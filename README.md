# 海拉鲁 · 水之庭

一池偏二次元风格的青蓝浅水。用简洁的浅深色层、自然起伏和随拨水推移、绕石形成的白沫表现流动；滑动水面时带动水流和白色波峰，不产生飞溅水花。

v1.9.0 增加「雪之野」和「云之境」。顶部切换水面、雪地、云层；当前会话内保留各场景的交互状态，共用晨光、暮色、月夜。设计与验证见 [雪地、云层设计及发布说明](docs/nature-history/release-v1.9.0.md)。

v1.10.0（历史版本）按用户提供的「Unity 动态云海」和「Unity 动态雪地」视频重做厚度表现：连续起伏的云海、可推开的云沟、具有压实底面和边缘积雪的立体雪痕。新增 WebGL 高度网格与方向光，保留 Canvas 2D 降级。参考分析、实现边界与验证见 [视频参考改版说明](docs/release-v1.10.0.md)。

v1.11.0 将雪地、雪球与云海改成直接渲染的 WebGL 3D 场景：透视相机、世界空间变形与拾取、球体网格和滚动四元数、闭合云层体积网格，共用深度遮挡。点击「视角」可切换俯视和斜视。性能降档仍使用 3D；能力不足时显示明确的不可用状态。实现与验证见 [3D 场景改版说明](docs/release-v1.11.0.md)。

v1.11.1 将划雪和拨云改为材料转移：中间下凹、两侧堆高，交叉划动可回填旧槽，反复扫满也保留起伏。聚云从周围收拢材料，见 [位移与堆积修正](docs/release-v1.11.1.md)。

v1.11.2 去掉雪地、云层可见范围内的矩形交互边界，痕迹可延伸到屏幕四边；扩展高度场、按相机分配网格，并共用平滑高度进行渲染与拾取，见 [无边界与平滑修正](docs/release-v1.11.2.md)。

- **雪地**：开阔雪面，不放置树木。划雪留下凹痕，长按压实；脚印模式可拖出连续足迹；「雪球」放下或收起一个雪球，拖动滚大。默认飘雪逐渐覆盖足迹，「新雪」清除足迹和雪球并恢复飘雪。
- **云层**：只需滑动拨开云海，触碰处局部变薄、散开，手指周围不堆高；云团继续自然漂移，间隙逐渐回拢。没有底部工具栏；轻点、按住不动与键盘空格 / Enter 不产生拨云或聚云效果。
- 雪地支持鼠标、触摸、多点触控和键盘空格 / Enter，云层支持鼠标和手指滑动、多点触控。切换和旋转屏幕保留雪地痕迹，页面隐藏暂停模拟。

## 玩法

- **游鱼**：池中有 5 条来自 Blender 模型与骨骼动画的小锦鲤，三种配色，缓慢游动并循环摆尾，随水流偏移与起伏；划水和落石会惊动附近的鱼，让它们加速摆尾、避开并下潜，之后慢慢放松。快速逃跑与急转弯会激起明显水纹，石头尚在空中就会提前避让；浅层慢游产生轻微尾流，鱼的真实表面参与水深材质，鱼身上方呈现与石头统一的浅色水块；石头可遮挡鱼。「平静」保留游鱼并清除惊吓。
- **拨水**：轻点起涟漪；滑动拨开水面并形成扩散的白色波峰，不出现沿途圆圈；长按后松手释放水波，均不产生飞溅水滴。支持多个手指同时触碰。
- **浮叶**：点击放叶；划动附近水面推动叶子，叶子也会随波漂动。最多 18 片。
- **落石**：选中后点水指定落点，随机大小的石头从画面上方加速落下。使用 Cannon 刚体物理，重复落点也能连续投放，石头互相碰撞、翻滚或堆住；入水减速并激起远大于手划的宽阔水波，移动后更新水深和波浪障碍。同时保留最近 10 块，继续落石会自动移除最早的一块；「平静」清除全部。
- **下雨**：打开雨势面板，直接选择小雨、中雨、大雨、暴雨或停雨。雨滴按俯视透视从镜头附近向各自水面落点收拢，中心附近呈短雨点；落水形成局部涟漪，约半秒消散。小雨、中雨、大雨、暴雨的雨纹半径分别为 1、1.33、1.67、2 倍，雨势越大，雨点越密、雨纹越大。手指拨水保留更宽、更持久的水波，与雨波叠加在同一水面上。小雨无雷，中雨偶有远雷，大雨雷电增多，暴雨频繁闪光照亮水面并伴随雷鸣。
- **光照**：右上角切换晨光、暮色、月夜。月夜有萤火。
- **声音**：默认开启，首次触摸、点击或空格 / Enter 操作自动启用播放，无声音开关。水声随交互播放，雨声随雨量变化，雷声延后于闪电。轻点播放用户提供的水滴录音，滑动循环播放用户提供的水流录音，音量随手速变化，停手后渐弱。水波还在荡漾时继续播放用户提供的荡漾录音，波纹越多、越强音量越大，波纹减少后平滑减弱、消散后淡出。落石在接触水面时播放用户指定的入水录音，保留自然起音与尾音。切换水面、雪地、云层时旧场景音效淡出，新场景声音淡入；快速连续切换也保持音量衔接。日常短音效仍直接播放，只在离开场景时柔和收尾。
- **平静**：停止雨丝、闪电和雷声，清除水波、水花，恢复三片初始浮叶。

水面聚焦后按空格或 Enter 也可触碰池中央。

## 开发与交付

v1.11.21 加入用户提供的三场景背景音乐，各场景单曲循环，切换时约 1.5 秒淡入淡出；新声源从曲目前半段随机起播，快速切回继续原来的播放进度。完整原始素材保留，音乐离线打包、按需解码，隐藏页面停止播放。见 [背景音乐发布说明](docs/release-v1.11.21.md)。

```sh
npm ci
npm start
# 重新生成程序水纹素材（仅修改生成算法时需要）
npm run assets
# 重新生成录音的离线播放数据
npm run audio
npm test
npm run check
npm run test:browser
npm run build
```

默认预览地址为 `http://127.0.0.1:8772`。`PORT` 环境变量可更改端口。

交付代码为 Chrome 61 / ES2017 基线的经典脚本，运行时不请求网络。开发构建依赖固定版本的 Cannon-es 与 esbuild，`npm run build` 自动重新打包物理引擎，也可单独运行 `npm run physics`。浏览器验证使用环境已有的 Playwright 与 Edge；可用 `CODEX_NODE_MODULES`、`BROWSER_CHANNEL` 指定验证运行时。

上传包：`artifacts/zelda-water-garden-minitool-v1.11.20.zip`。`src/` 的 26 个静态文件进入 ZIP，入口位于包根。v1.11.20 修复云层滑动时的堆高边缘，见 `docs/release-v1.11.20.md`。v1.11.19 移除云海工具栏，仅保留滑动交互，见 `docs/release-v1.11.19.md`。v1.11.18 为场景切换增加双向声音淡入淡出，见 `docs/release-v1.11.18.md`。v1.11.17 移除雪地树木，见 `docs/release-v1.11.17.md`。v1.11.16 移除声音开关，首次操作自动播放默认开启的声音，见 `docs/release-v1.11.16.md`。v1.11.15 增加随实际水波强弱变化、松手后持续的荡漾录音，见 `docs/release-v1.11.15.md`。v1.11.14 接入用户指定的石头入水录音，见 `docs/release-v1.11.14.md`。v1.11.13 合并雪地、云层场景与本地雨势连续过渡、录音和长声音淡入淡出，保留冰霜移除，见 `docs/release-v1.11.13.md`。降雨与音频改动见 `docs/release-v1.9.6.md` 至 `docs/release-v1.9.13.md`；雪地、云层改动见 `docs/release-v1.10.0.md` 至 `docs/release-v1.11.12.md`。锦鲤发布记录与证据保存在 `docs/fish-history/`，Blender 制作源文件在 `assets-source/fish/`。

WebGL 1 用于真正的三维水面网格、顶点位移、实时法线与卡通光照；能力不足时暂停并显示 3D 状态说明，上下文恢复后重建低档资源。纹理最长边 1024，默认画布 DPR ≤ 1.5、像素 ≤ 200 万，低档 DPR ≤ 1、像素 ≤ 100 万；基础场景每帧 6 次 draw call（含鱼群的 1 次 / 1175 个三角形），动态落石最多增加 2 次和 420 个三角形。立体池岸、144 块几何岸石、动态石头、阴影与半透明水面共用深度缓冲。石头露出部分遮挡水面、水下部分透出水色；草叶与蕨类仍为地形材质。页面隐藏时暂停模拟与音频。

空中雨滴与环境闪光复用现有 Canvas 2D 覆盖层，不增加 WebGL 纹理、几何或 draw call。小雨、中雨、大雨、暴雨分别有 48、168、420、840 个空中雨滴，分别最多每秒生成 20、100、280、640 次有效涟漪；低档为 40%，暴雨 336 个空中雨滴。雨滴使用固定容量的局部波形（默认 384 / 低档 160），在现有波场中叠加短寿命高度，驱动同一水面网格、法线与浮叶；石头的干燥区域不产生雨波。雨波不进入手指水波的长寿命传播求解器，因此不形成全池大波。停雨后约半秒清除已有雨纹。雨声、雷声复用程序生成的音频缓冲，轻点与滑动复用录音解码缓冲，不请求网络；停手、重置、切换场景和隐藏页面会淡出或释放拨水音频。减少动态效果偏好会进一步减少雨滴并减弱闪光。

雪地、云层与单雪球开关见 docs/release-v1.11.11.md。云下大地与回卷效果见 v1.11.9、v1.11.10 发布记录。

浏览器自动化通过不等于真机通过。Android 8.1 / Chrome 61、iOS 小红书 WebView 的视觉兼容性、实际音频和性能尚未实测。

水色按水面与实际三维池底 / 石面的高度差计算；露出水面的石头在波场中阻挡并反射水波，水下石面形成浅水区。计算方式与近似限制见 docs/release-v1.7.1.md。
