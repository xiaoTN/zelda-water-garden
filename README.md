# 海拉鲁 · 水之庭

一池偏二次元风格的青蓝浅水。用简洁的浅深色层、自然起伏和随拨水推移、绕石形成的白沫表现流动；滑动水面时带动水流和白色波峰，不产生飞溅水花。冰面参考《原神》冻结水面的浅蓝透白、密集不规则冰纹和亮色边缘，以原创程序材质绘制。

## 玩法

- **拨水**：轻点起涟漪；滑动拨开水面并形成扩散的白色波峰，不出现沿途圆圈；长按后松手释放水波，均不产生飞溅水滴。支持多个手指同时触碰。
- **浮叶**：点击放叶；划动附近水面推动叶子，叶子也会随波漂动。最多 18 片。
- **冰霜**：点水让晶纹向外生长、凝成薄冰；点冰先裂开，再弹出碎冰、露出水洞。滑动水面能画冰径，从冰面开始滑动则连续碎冰。
- **一键冰封 / 融冰**：选中冰霜后出现。整池冰封后可逐块踩碎，也可融化全部冰层。冰会固定浮叶、阻挡水波；横竖屏切换保留冰层和水洞。
- **落石**：选中后点水指定落点，随机大小的石头从画面上方加速落下。使用 Cannon 刚体物理，重复落点也能连续投放，石头互相碰撞、翻滚或堆住；入水减速并激起水波，撞冰破冰，移动后更新水深和波浪障碍。最多 10 块，「平静」清除。
- **下雨**：打开雨势面板，直接选择小雨、中雨、大雨、暴雨或停雨。雨丝从上方落下并在落点激起小波纹；雨越大，雨丝越密、更长，风斜和阴云也更明显。小雨无雷，中雨偶有远雷，大雨雷电增多，暴雨频繁电闪雷鸣。
- **光照**：右上角切换晨光、暮色、月夜。月夜有萤火。
- **声音**：手动开启合成水声、冰裂声、随雨量变化的雨声和延后于闪电的雷声。默认静音。
- **平静**：停止雨丝、闪电和雷声，清除水波、水花、冰层和碎冰，恢复三片初始浮叶。

水面聚焦后按空格或 Enter 也可触碰池中央。

## 开发与交付

```sh
npm ci
npm start
# 重新生成程序水纹素材（仅修改生成算法时需要）
npm run assets
npm test
npm run check
npm run test:browser
npm run build
```

默认预览地址为 `http://127.0.0.1:8772`。`PORT` 环境变量可更改端口。

交付代码为 Chrome 61 / ES2017 基线的经典脚本，运行时不请求网络。开发构建依赖固定版本的 Cannon-es 与 esbuild，`npm run build` 自动重新打包物理引擎，也可单独运行 `npm run physics`。浏览器验证使用环境已有的 Playwright 与 Edge；可用 `CODEX_NODE_MODULES`、`BROWSER_CHANNEL` 指定验证运行时。

上传包：`artifacts/zelda-water-garden-minitool-v1.9.0.zip`。只有 `src/` 的 14 个静态文件进入 ZIP，入口位于包根。研究、发布说明和验证截图在 `docs/`。v1.9.0 增加雨丝、四档雨势及雷电联动，见 `docs/release-v1.9.0.md`。v1.8.3 修正石堆接触抖动与成组休眠，见 `docs/release-v1.8.3.md`。v1.6 增加三维水面与流动法线 / 泡沫贴图，见 `docs/release-v1.6.0.md`。v1.5 改为二次元水面与冰元素风格，研究和对照见 `docs/anime-water-ice-study-v1.5.0.md`。

WebGL 1 用于真正的三维水面网格、顶点位移、实时法线与卡通光照；能力不足、持续慢帧或上下文丢失会进入 Canvas 2D 水面。纹理最长边 1024，默认画布 DPR ≤ 1.5、像素 ≤ 200 万，低档 DPR ≤ 1、像素 ≤ 100 万；基础场景每帧 5 次 draw call，动态落石最多增加 2 次和 420 个三角形。立体池岸、144 块几何岸石、动态石头、阴影与半透明水面共用深度缓冲。石头露出部分遮挡水面、水下部分透出水色；草叶与蕨类仍为地形材质。页面隐藏时暂停模拟与音频。

天气复用现有 Canvas 2D 覆盖层，不增加 WebGL 纹理、几何或 draw call。暴雨默认最多 260 条雨丝，低档 117 条；落水计算有独立预算。雨声和雷声复用程序生成的音频缓冲，不请求网络。减少动态效果偏好会减少雨丝、取消闪电折线并减弱闪光。

浏览器自动化通过不等于真机通过。Android 8.1 / Chrome 61、iOS 小红书 WebView 的视觉兼容性、实际音频和性能尚未实测。

水色按水面与实际三维池底 / 石面的高度差计算；露出水面的石头在波场中阻挡并反射水波，水下石面形成浅水区。计算方式与近似限制见 docs/release-v1.7.1.md。
