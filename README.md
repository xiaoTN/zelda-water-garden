# 海拉鲁 · 水之庭

一池偏二次元风格的青蓝浅水。用简洁的浅深色层、自然起伏和随拨水推移、绕石形成的白沫表现流动；滑动水面时带动水流和白色波峰，不产生飞溅水花。冰面参考《原神》冻结水面的浅蓝透白、密集不规则冰纹和亮色边缘，以原创程序材质绘制。

## 玩法

- **游鱼**：池中有 5 条来自 Blender 模型与骨骼动画的小锦鲤，三种配色，缓慢游动并循环摆尾，随水流偏移与起伏；划水和落石会惊动附近的鱼，让它们加速摆尾、避开并下潜，之后慢慢放松。快速逃跑与急转弯会激起明显水纹，石头尚在空中就会提前避让；浅层慢游产生轻微尾流，鱼的真实表面参与水深材质，鱼身上方呈现与石头统一的浅色水块；石头与冰面可遮挡鱼。「平静」保留游鱼并清除惊吓。
- **拨水**：轻点起涟漪；滑动拨开水面并形成扩散的白色波峰，不出现沿途圆圈；长按后松手释放水波，均不产生飞溅水滴。支持多个手指同时触碰。
- **浮叶**：点击放叶；划动附近水面推动叶子，叶子也会随波漂动。最多 18 片。
- **冰霜**：点水让晶纹向外生长、凝成薄冰；点冰先裂开，再弹出碎冰、露出水洞。滑动水面能画冰径，从冰面开始滑动则连续碎冰。
- **一键冰封 / 融冰**：选中冰霜后出现。整池冰封后可逐块踩碎，也可融化全部冰层。冰会固定浮叶、阻挡水波；横竖屏切换保留冰层和水洞。
- **落石**：选中后点水指定落点，随机大小的石头从画面上方加速落下。使用 Cannon 刚体物理，重复落点也能连续投放，石头互相碰撞、翻滚或堆住；入水减速并激起远大于手划的宽阔水波，撞冰破冰，移动后更新水深和波浪障碍。同时保留最近 10 块，继续落石会自动移除最早的一块；「平静」清除全部。
- **下雨**：打开雨势面板，直接选择小雨、中雨、大雨、暴雨或停雨。雨滴按俯视透视从镜头附近向各自水面落点收拢，中心附近呈短雨点；落水形成局部涟漪，约半秒消散。小雨、中雨、大雨、暴雨的雨纹半径分别为 1、1.33、1.67、2 倍，雨势越大，雨点越密、雨纹越大。手指拨水保留更宽、更持久的水波，与雨波叠加在同一水面上。小雨无雷，中雨偶有远雷，大雨雷电增多，暴雨频繁闪光照亮水面并伴随雷鸣。
- **光照**：右上角切换晨光、暮色、月夜。月夜有萤火。
- **声音**：手动开启合成水声、冰裂声、随雨量变化的雨声和延后于闪电的雷声。滑动播放连续的拨水声和细碎气泡声，随手速变化，停手后渐弱。默认静音。
- **平静**：停止雨丝、闪电和雷声，清除水波、水花、冰层和碎冰，恢复三片初始浮叶。

水面聚焦后按空格或 Enter 也可触碰池中央。

## 开发与交付

```sh
npm ci
npm start
# 重新生成程序水纹素材（仅修改生成算法时需要）
npm run assets
npm test
npm run check
npm run test:browser
npm run build
```

默认预览地址为 `http://127.0.0.1:8772`。`PORT` 环境变量可更改端口。

交付代码为 Chrome 61 / ES2017 基线的经典脚本，运行时不请求网络。开发构建依赖固定版本的 Cannon-es 与 esbuild，`npm run build` 自动重新打包物理引擎，也可单独运行 `npm run physics`。浏览器验证使用环境已有的 Playwright 与 Edge；可用 `CODEX_NODE_MODULES`、`BROWSER_CHANNEL` 指定验证运行时。

上传包：`artifacts/zelda-water-garden-minitool-v1.9.8.zip`。`src/` 的 17 个静态文件进入 ZIP，入口位于包根。v1.9.8 按雨势逐档放大雨纹，暴雨半径为小雨两倍，见 `docs/release-v1.9.8.md`。v1.9.7 加密中雨、大雨，将暴雨密度翻倍，见 `docs/release-v1.9.7.md`。v1.9.6 区分雨滴和拨水的半径与寿命，滑动改为连续水声，见 `docs/release-v1.9.6.md`。v1.9.5 消除鱼身硬色块，使用连续背腹配色和平滑光照，见 `docs/release-v1.9.5.md`。v1.9.4 整合四档俯视降雨、共享水波、雷电与主分支的锦鲤、水面抗锯齿及落石避让，见 `docs/release-v1.9.4.md`。雨效历史保留在 `docs/release-v1.9.0.md` 至 `docs/release-v1.9.3.md`；同期主分支的锦鲤发布记录与证据保存在 `docs/fish-history/`。Blender 制作源文件在 `assets-source/fish/`；水面边缘平滑记录见 `docs/release-v1.8.6.md`。

WebGL 1 用于真正的三维水面网格、顶点位移、实时法线与卡通光照；能力不足、持续慢帧或上下文丢失会进入 Canvas 2D 水面。纹理最长边 1024，默认画布 DPR ≤ 1.5、像素 ≤ 200 万，低档 DPR ≤ 1、像素 ≤ 100 万；基础场景每帧 6 次 draw call（含鱼群的 1 次 / 1175 个三角形），动态落石最多增加 2 次和 420 个三角形。立体池岸、144 块几何岸石、动态石头、阴影与半透明水面共用深度缓冲。石头露出部分遮挡水面、水下部分透出水色；草叶与蕨类仍为地形材质。页面隐藏时暂停模拟与音频。

空中雨滴与环境闪光复用现有 Canvas 2D 覆盖层，不增加 WebGL 纹理、几何或 draw call。小雨、中雨、大雨、暴雨分别有 48、168、420、840 个空中雨滴，分别最多每秒生成 20、100、280、640 次有效涟漪；低档为 40%，暴雨 336 个空中雨滴。雨滴使用固定容量的局部波形（默认 384 / 低档 160），在现有波场中叠加短寿命高度，驱动同一水面网格、法线与浮叶；冰和石头的干燥区域不产生雨波。雨波不进入手指水波的长寿命传播求解器，因此不形成全池大波。Canvas 降级用相同半径与寿命绘制小雨纹。停雨后约半秒清除已有雨纹。雨声、雷声和连续拨水声复用程序生成的音频缓冲，不请求网络；停手、静音、重置和隐藏页面会淡出或释放拨水音频。减少动态效果偏好会进一步减少雨滴并减弱闪光。

浏览器自动化通过不等于真机通过。Android 8.1 / Chrome 61、iOS 小红书 WebView 的视觉兼容性、实际音频和性能尚未实测。

水色按水面与实际三维池底 / 石面的高度差计算；露出水面的石头在波场中阻挡并反射水波，水下石面形成浅水区。计算方式与近似限制见 docs/release-v1.7.1.md。
