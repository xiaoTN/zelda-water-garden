# v1.16.6 — 继续创造，不打断停留

达到物体数量上限时继续创建新的物体，并自动移除最早创建的一件。纸船与雪球改为这一行为，浮叶和落石沿用已有的替换逻辑：纸船十二艘、雪球十二个、浮叶十八片、落石十块。场景中的数量保持有界，绘制和物理预算不增加。

移除放置纸船、落石、水边无效点击及雪球数量相关的提示。有效位置的新物体正常生成，无效位置静默跳过；无效参数、岸边、障碍和其他船的碰撞不会误删旧物体。纸船满额时可占用即将移除的最早纸船的位置，但仍检查其余碰撞。

移除的纸船和雪球立即停止运动，并解除对应手指的拖动引用。多指同时操作时，其他手指继续操作；旧指针随后移动或松手不再驱动已移除的物体。落石移除时释放旧物理刚体，浮叶由现有队列替换，不保留额外渲染对象。
