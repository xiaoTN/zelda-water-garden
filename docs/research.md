# 水面研究与实现决策

此文记录 v1.0 的初始方向。v1.1 已针对《旷野之息》实机图片重新分析并重做水材质，现行依据见 [七张图片对照](botw-water-study-v1.1.0.md)。

研究日期：2026-10-03。目标：把用户希望的塞尔达水面观感，转成小红书离线 H5 内可直接触碰的一池水。

## 可核验来源

1. [任天堂《王国之泪》青沼英二实机演示介绍](https://www.nintendo.com/my/news/article/2s5YEZZolOMiN31Guh461K)，发布于 2023-03-30。页面包含官方演示和造船渡水的实机图片。相应的[任天堂官方演示视频](https://www.youtube.com/watch?v=a6qna-ZCbxA)发布于 2023-03-28。
2. [任天堂 Ask the Developer Vol. 9 Part 2](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-2/)，发布于 2023-05-09。开发者谈到将玩法、机制、视觉和声音统一到世界体验中。它支持设计方向，不提供水面 shader 的参数或实现。
3. [GDC 2017：Change and Constant — Breaking Conventions with Breath of the Wild](https://www.gdcvault.com/play/1024562/Change-and-Constant-Breaking-Conventions)。任天堂导演、美术与技术负责人介绍《旷野之息》的设计与实现。本次能访问的是会议页面与摘要，未把摘要当作水模拟的技术披露。
4. [Evan Wallace 的 WebGL Water 交互演示](https://madebyevan.com/webgl-water/)。用于研究网页中水面交互的表现与可行性；本工具使用自行编写的波场和 shader，不引入该演示代码或库。

另通过图片检索观察湖岸、浅滩、落水和浮叶等画面主题。Wiki 与社区图像只作视觉参考，不作为任天堂底层实现的证据，也没有进入上传包。

## 提取的视觉方向

以下是面向小屏水池的设计归纳，不是对游戏原版渲染方法的断言：

- 水色以青绿、玉色、浅岸的暖绿为主；岸边浅，中央更深。
- 水底可见砂石，光纹缓慢流动；水波会改变底部图案的位置和反光。
- 波纹以较亮的细线和波峰提示触碰，不用屏幕上大面积的纯白遮盖水。
- 落石比指尖更有力量，水滴先飞起后落下；滑动留下连续扰动。
- 让风、浮叶和昼夜光照延续宁静的旷野氛围，避免把水面做成等待按钮启动的演示。

## 技术与平台取舍

- 主线程二维高度场，以固定 60 Hz 步长模拟邻域传播、岸边反射和阻尼。展示按 30 FPS 设计，模拟与显示分离。
- 水面高度以 RG 两通道打包进一张小型 RGBA8 纹理。WebGL 1 片元 shader 计算法线、底部折射、明暗波峰与程序化光纹。
- 水底、岩石、沙岸、草与蕨叶以固定随机种子生成一次 Canvas 纹理；没有模型加载、网络请求、Worker 或 WASM。
- 连续拖动在路径上分段加入扰动；长按积蓄扰动并在松手释放。多个指针独立管理，取消事件清理手势。
- 声音默认关闭，只在用户开启后使用 Web Audio 合成，不使用游戏音频。
- 中档渲染预算与慢帧观测驱动降级；初始化失败和 context 丢失时保留可触碰的 Canvas 水池。二维降级模式保留涟漪、水花、浮叶与玩法，省略实时水底折射。

这是塞尔达观感启发下的原创场景与交互重建，未声称逐像素复刻、采用原版 shader 或游戏引擎的流体求解方式。
