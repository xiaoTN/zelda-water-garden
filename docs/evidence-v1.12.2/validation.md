# v1.12.2 踩碎后的局部雪堆验证

日期：2026-10-05。环境：Windows，Edge 154.0.4258.53。

- 将碎雪堆积范围收拢为原球半径的 1.9 倍，取消为限制高度而向远处扩散的逻辑。碎雪权重形成较高的局部雪丘与较低的间隙，容纳不同大小雪球的原体积。鞋底压出的雪使用宽而平滑的局部肩部，避免高雪堆旁的窄尖峰。
- `npm run build` 全部 95 项测试通过。新增三种半径（0.035、0.085、0.18，覆盖合并大球）的局部范围与高低差验证：堆积范围外的原始高度单元完全不变，平滑后的远处雪面也不变；各尺寸均有明显峰谷与随尺寸增长的峰高。已有体积、边界堆积、鞋底、滚动、合并、旧指针与重置验证通过。
- 新增窄高雪丘的射线拾取验证，两种相机视角都正确拾取可见顶部。高雪堆场景使用 0.025 世界单位的射线步长；普通雪面与云层仍保留原步长。
- `npm run test:browser` 通过，共 70 个场景：慢帧恢复 3 个、水面 43 个、自然场景 12 个、形变 12 个。三份带错误数组的报告均为空。
- 四种视口、两档质量、俯视 / 斜视共 16 组踩碎交互通过。局部环形采样的峰谷差为 0.255–1.040 世界单位，峰高为 0.358–0.828 世界单位；三个远处取样位置的高度变化全部严格为零。鞋底凹痕、其他雪球保留、旧球指针失效继续通过。具体数据见 `nature-browser-report.json`。
- 复用现有 RGBA 高度纹理，以 G+B 表示更高的局部雪堆。16 组验证的最大编码误差低于 0.000124 深度单位（对应约 0.000047 世界高度单位），无字节回绕或高度截断；雪丘最高处的相机拾取误差低于 0.000001 世界单位。
- `snow-crushed-footprint.png` 保存自动化斜视画面。用户预览 `http://127.0.0.1:8773/` 已刷新，实际滑动滚球、继续滚大、脚印踩碎及视角切换后，周围局部隆起与远处平整已检查；画面见 `local-heap-preview.png`、`local-heap-oblique-preview.png`。
- 沿用同一雪面网格、材质、光照、深度与球体支撑。满场 12 球默认档 98,624 个三角形、低档 38,472 个，均为 14 次绘制；几何、逐球拾取、雪面接触、上下文恢复、尺寸变化、离线、触摸回退与不可用状态继续通过。没有增加纹理、网格或绘制调用。
