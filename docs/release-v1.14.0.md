# v1.14.0 — 雪球惯性与本机调参

快速甩动后松手，雪球会沿最近的手势方向继续滚动，按摩擦和阻尼逐渐停下。速度取最近约 120 ms 的世界坐标位移与手势事件时间戳，独立于渲染帧时钟；停顿超过 100 ms 再松手、缓慢释放、触摸取消不会甩出。再次抓住运动中的球立即停止惯性。雪球沿用真实球体、相机拾取、雪原接触、旋转、积雪增长和压痕；合并守恒体积并合并动量，扩展雪原边界停止对应方向的移动。

惯性采用最长 20 ms 的子步及摩擦、阻尼的解析积分，既保留扫掠碰撞又减少不同帧率的距离差异。停住的球不再更新运动。运动列表复用固定工作区，仍至多十二个雪球，不增加网格数量。惯性滚动继续驱动原录音，结束后淡出；场景切换、页面退出、失焦或渲染中断停止惯性。

仅在本机 HTTP/HTTPS 的 localhost、IPv4/IPv6 回环地址展示“开发者参数 · 本机”，宽屏展开、窄屏收起。滑块和数字输入实时调整十三项参数，包括雪球惯性、摩擦、触发速度、上限、增长，划雪与雪痕回填，拨水力度，拨云范围、羽化范围、侧推力度、恢复速度，场景切换时长。设置保存在当前浏览器，支持恢复默认和查看参数 JSON；正式容器与离线入口隐藏且不加载调试存储。详见 `developer-tuning.md`。
