# 水之庭 v1.9.8 · 雨纹随雨势逐档增大

四档雨势增加明确的雨纹空间倍率，小雨为 1、中雨为 4/3、大雨为 5/3、暴雨为 2。天气落水回调将倍率传入波场，每滴保存落水时的尺寸，切换雨势后已有雨纹按原尺寸自然消散。雨纹半径与波峰带宽同步缩放，实际水面高度、法线及 Canvas 降级使用同一尺寸；Canvas 通过共享半径函数绘制，线宽也随雨势增加。
