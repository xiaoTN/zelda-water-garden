# 水之庭 v1.9.0 · Blender 锦鲤与摆尾动画

在 Blender 5.2.2 LTS 中制作一条原创低面数锦鲤：圆润的立体鱼身、分叉尾鳍、胸鳍、背鳍和眼睛。Head / Body / Tail 三节骨骼与渐变权重带动身体后段、尾柄和尾鳍，动画为 24 FPS 的一秒循环，尾部摆幅大于头部。

可编辑源文件为 `assets-source/fish/garden-koi.blend`，通用带动画模型为 `garden-koi.glb`。制作脚本、材质与导出说明见 `assets-source/fish/README.md`。网页使用从 Blender 依赖图实际求值、采样导出的同一套动画数据；没有另行在网页中重新生成鱼的模型或用公式替代其摆尾。

## 场景行为

- 五条鱼共用模型，有红白、金色、青白三种配色，体型、游速和动作相位略有不同。水下慢游时逐渐转向，以鱼身周围的探测点避开岸边和已存在的石头。
- 鱼以水下颜色绘制，使用真实三维深度测试接受石头遮挡；冰层通过现有覆盖场遮挡鱼。运动中的波场给投影带来轻微偏移，晨光、暮色、月夜沿用场景色调。
- 横竖屏切换保留鱼的池中位置。重置水面保留鱼群。页面隐藏时随主循环暂停，减少动态效果设置下停止游动与摆尾。
- Canvas 2D 降级使用同一份 Blender 姿态数据的简化三角面投影，并根据水深和冰层遮挡。

## 资源与验证

- 单条鱼 141 个共享顶点、235 个三角形；五条鱼合计 1175 个三角形，WebGL 增加 1 个缓冲和 1 次绘制，不增加纹理或外部依赖。动画数据脚本约 50 KiB，复用运行时顶点数组。
- 新增模型动画回归检查索引、24 帧姿态、首尾循环连续性、尾部相对头部的摆幅，以及 GLB 中实际存在蒙皮和骨骼动画。
- 四种宽高比下连续模拟游动，验证鱼保持在水下、岸边及障碍外、速度有界、动画缓冲复用和减少动态效果设置。
- 浏览器通过像素差验证鱼确实可见、姿态变化可见、完整冰层和实体石面能够遮挡。四种视口、连续落石、触控、冰霜、光照、上下文丢失恢复、离线文件和逐级降档全部通过。
- 34 项单元测试和 14 个浏览器场景通过，错误数组为空。包检查、构建、源码审计、ZIP 内容一致性检查与体积审计通过，0 警告。截图与完整报告在 `evidence-v1.9.0/`。
