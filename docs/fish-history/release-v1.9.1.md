# 水之庭 v1.9.1 · 游鱼与水面双向互动

原来的鱼只按游动方向前进，波场仅改变投影外观，也没有手势感知。本次把鱼的位置、游速、游深与已有波场、划水及落石连接起来，继续使用 Blender 导出的同一套摆尾动画。

## 行为

- 触碰和划水按手势线段与鱼的距离触发受惊，快速划动影响更明显；远处的鱼不会一起惊散。落石投放和入水冲击也会惊动附近的鱼。
- 受惊鱼快速转向远离刺激源、加速游动、加快 Blender 动画播放，并稍微下潜。惊吓随时间衰减，逐渐恢复慢游；动画相位连续，不因速度变化跳帧。下潜后的颜色与透明度随深度变化。
- 从波场采样的坡度驱动有阻尼的水平漂移，水面高度影响鱼身起伏。较强的外来水波也会触发短暂警觉；自己的微小尾流低于阈值，不形成自我惊吓循环。
- 浅层游鱼在前后方注入成对的小波峰 / 波谷，进入现有波场传播，深游时衰减，完整冰面下停止注入。没有增加装饰圆圈、粒子或波纹贴片。
- 鱼之间保持少量间距。避障优先于逃跑；若新石头直接覆盖鱼的当前位置，允许鱼在遮挡下连续游出，不瞬移或永久卡住。
- 「平静」同时清除惊吓和水流惯性，并短暂抑制鱼的尾流，让水面立即安静。随后恢复自然活动。减少动态效果模式继续停用游动和摆尾。

## 水深的处理边界

鱼是悬浮在水中的移动物体，不能直接作为池底高度写入水深贴图，否则鱼身上方会出现与石头相同的浅水色块。本次通过小范围成对波场扰动近似鱼的排水与尾流；鱼的实际三维高度用于遮挡及水下颜色。这是适合离线小工具预算的双向近似，并非完整三维流体、浮力或体积守恒求解器。

## 验证

- 新增确定性回归：近处划水惊吓 / 远处不受影响、加速摆尾、下潜与恢复；水波改变实际位置；尾流能量有界且不会自我惊吓；不改写池底水深与干湿掩码；冰面下不注入尾流；新落石覆盖后的连续脱离。
- 浏览器在四种视口中实际拖动指针经过鱼的附近，检查惊吓、加速、下潜、无装饰圆圈，并验证「平静」清除惊吓。
- 原有 Blender 动画、鱼的水下显示、石头和冰面遮挡、连续落石、触控、上下文恢复、离线打开和逐级降档检查保留。局部结冰检查允许未结冰区域保留小量鱼的自然尾流。
- 资源预算保持五条鱼 / 1175 个三角形 / 一次鱼群绘制，无新增素材、纹理或依赖。使用固定鱼群状态与复用顶点数组，不重建水深贴图。
- 37 项单元测试、18 个浏览器场景通过，浏览器错误数组为空。四种视口的手势检查中，鱼受惊后的实测游速约为原来的 3.2–3.7 倍。
- 包检查、构建、源码审计、ZIP 源码字节一致性检查与体积审计全部通过，0 警告；ZIP 为 15 个静态文件、452,097 字节。
