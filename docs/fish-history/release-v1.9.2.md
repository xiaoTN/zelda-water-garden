# 水之庭 v1.9.2 · 鱼参与统一水深材质

按用户的视觉要求，将 Blender 三维鱼放回水面之前的实体绘制阶段；水材质覆盖鱼身，并读取鱼表面的实际高度。鱼上方现在形成与石头相同色阶的浅色水块，轮廓随鱼身、尾鳍和游动同步变化，下潜时水色自然加深。

删除原先在水面之后叠加、单独着水下色的鱼渲染方式。鱼与石头、池底共用已有的水深颜色和透明度公式，受惊、摆尾、避障及水流双向互动保留。

## 实现与预算

- 每帧光栅化当前动画鱼的实际三角形与投影位置，将鱼表面高度合入用于显示的水深纹理。与实体池底取较高表面，沿用五点可分离滤波平滑动态边缘。
- 复用动态高度、滤波行与像素数组，每帧从当前实体水深恢复，鱼游过不会留下旧色块。普通档最多额外使用 3 MiB CPU 缓冲；复用既有水深纹理，无新增 GPU 纹理或绘制次数。
- 物理池底、刚体碰撞、岸边距离和干湿掩码保持独立，避免鱼把自己当成池底障碍，或在尾鳍旁生成岸边白沫。鱼的动态高度确实进入水材质的 depth 计算。
- Canvas 2D 降级使用同一浅水 / 深水色阶和透明度，对鱼的三角面高度进行简化投影着色。
- 本机 Node 单独测量 512×512 显示水深合成，预热 10 次后测量 40 次，中位耗时约 0.43 ms、P95 约 2.19 ms。该数据不含 GPU 上传，也不代表真机帧率。

## 验证

- 新增普通档与低档回归：真实鱼面使显示水深变浅、移动后轮廓改变、移除鱼后完全恢复、缓冲复用、实体池底及其他纹理通道不被改写。
- GPU 回归临时隐藏鱼自身的颜色绘制，仍能检测到水材质因鱼的几何深度而改变，排除仅靠鱼的着色伪造浅水效果。
- 保留鱼动画、冰面和石头遮挡、四种视口的划水惊吓、落石、波纹边缘、上下文恢复、降档和离线检查。
- 38 项单元测试、18 个浏览器场景全部通过，错误数组为空。包检查、构建、源码审计、ZIP 字节一致性与体积审计通过，0 警告。ZIP 包含 15 个静态文件、452,768 字节。
