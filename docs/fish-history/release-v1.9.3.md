# 水之庭 v1.9.3 · 急游水纹与落石避让

鱼受惊后更快加速、掉头，逃跑速度增量从 0.15 提高至 0.36（世界单位 / 秒，按视口缩放）。摆尾沿用 Blender 动画并随速度加快，惊吓消退后恢复慢游。

快速游动向现有波场注入前后成对的扰动，急转弯增加侧向成对扰动；水纹随速度、转向和深度变化，逃跑下潜后仍有衰减后的尾流。继续共用已有水面材质，没有新增装饰波纹线。平静和冰面仍抑制尾流。

石头下落期间，每帧根据高度、重力及当前速度预测入水位置，提前惊动附近鱼；接近水面时增强惊吓。入水后的石头不再持续刷新空中威胁，原有入水冲击反馈保留。
