# v1.16.1 — 纸船顺着水流漂动

纸船接入与浮叶方向一致的水流作用：附近拨水沿手指移动方向推船，实际水面波场的局部坡度推动船身，平静时随缓慢环境水流漂动。保留原来的随波升降、俯仰与侧倾。波纹推动有适合纸船的力度，普通和低档均采样当前波场，雨波也包含在采样中。

水流速度与手指甩出的速度分别记录、衰减，再一起决定世界坐标中的移动；保留惯性触发阈值和总速度上限。拖动/快速滑行时船头跟随手势或实际运动，缓慢顺流时轻柔转向；微小波动不频繁改变朝向。继续用真实船身轮廓检查平移和转向，遇到岸边、石头或其他船会阻止穿越。抓住船时立即停止水流漂动，松手后重新受水流影响；页面隐藏、失焦、场景切换和 WebGL 中断清除运动速度。

本机开发者面板增加一行“水流推动力度”，默认 1，范围 0–3，实时生效并保存到本机设置。0 关闭附近拨水、波纹与环境水流的推动，手动拖动与甩出仍可使用。减少动态效果偏好关闭环境水流，保留实际交互和波纹作用。

被动漂动不生成自己的驱动波纹，避免自身水纹不断推船或水声永不停歇；实际手指拖动和甩出继续带起水纹。没有新增几何、贴图、draw call 或外部素材，最多仍为十二艘真实折纸网格。
