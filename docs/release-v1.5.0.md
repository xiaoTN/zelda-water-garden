# 水之庭 v1.5.0 · 二次元水面与冰晶

2026-10-03。按用户要求改为卡通水面，增加沿岸泛白水纹；参考《原神》冻结水面的实机效果重绘冰材质；移除落石玩法。

水面采用青蓝浅深色层、稀疏的亮色波纹和三层岸边白沫，替换写实镜面高光与密集反射。冰面采用浅蓝晶面、不规则细密冰纹、霜白与亮边，冻结时出现短暂雪晶，碎片改成蓝白晶片。参考与实现对应关系见 [调研记录](anime-water-ice-study-v1.5.0.md)。

原有滑动水花、多点触摸、长按、浮叶、细雨、三种光照、水声、局部 / 全池冻结、踩碎、融冰和画冰径均保留。落石按钮、提示、事件逻辑已删除，工具栏只保留拨水、浮叶、冰霜三种模式。
