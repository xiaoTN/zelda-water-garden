# v1.9.0 · 雪之野与云之境

日期：2026-10-04。

## 交互设计

在同一个离线工具里增加两种自然场景。顶部为水面 / 雪地 / 云层选择器，底部只显示当前场景的三种玩法与天气、声音、重置。沿用水之庭的宋体标题、克制配色、沉浸式全屏画面；雪地使用远山、松树与新雪，云层使用天光与柔和的云团。三个场景共用晨光、暮色和月夜。

| 场景 | 轻点 / 按住 | 拖动 | 环境变化 | 重置 |
| --- | --- | --- | --- | --- |
| 雪地 · 划雪 | 压下凹痕；长按加深 | 连续雪沟与边缘堆雪 | 飘雪渐渐覆盖痕迹 | 新雪清除雪痕、脚印与雪球 |
| 雪地 · 脚印 | 留下一枚脚印 | 按距离交替左右脚 | 足迹在未下雪时保留 | 同上 |
| 雪地 · 雪球 | 放下或选中雪球 | 滚动增大，留下压痕 | 最多 12 个雪球 | 同上 |
| 云层 · 拨云 | 按住推开、消散局部云雾 | 打开一条云隙 | 云雾慢慢恢复 | 云海恢复初始云团 |
| 云层 · 聚云 | 云团向指尖聚拢 | 带着附近云团移动 | 松手后保留惯性 | 同上 |
| 云层 · 送风 | 送出轻风 | 风向跟随手势 | 微风持续推动整个云海 | 同上 |

切换场景保留当前会话的状态；天气分别保存，光照与声音共享。停止渲染和模拟未显示的场景，场景切换取消当前手势。页面隐藏暂停 RAF 和声音，恢复时不补算积累时间。横竖屏变化取消手势，保留归一化坐标下的雪痕、雪球和云团。

## 实现与预算

- `nature-core.js`：独立的雪地高度场和云团运动模型，可在 Node 中验证。320 × 320 雪地网格限制压实深度；按手势路径插值，快速拖动不会留下断点。雪痕通过高度差法线表现凹陷和边缘积雪。
- `nature-renderer.js`：Canvas 2D 场景；背景缓存，雪痕只在数据或光照改变时重绘。云团由 4 张 256 × 180 的程序密度材质构成，切换场景 / 光照时预计算，帧内仅绘制复用的精灵。
- 云团固定 72 组、雪球最多 12 个、飘雪最多 70 个可见粒子。画布沿用 DPR ≤ 1.5、像素 ≤ 200 万的预算；持续慢帧时降为 DPR 1。新场景不依赖 WebGL，也不增加外部素材或网络请求。
- 减少动态效果偏好关闭自动云漂移、起伏和飘雪粒子，保留用户直接操作与状态反馈。低端设备的实际帧率未实测。
- 手势由原有 Pointer Events / Touch Events 入口统一路由；修正无 PointerEvent 时重复注册全局鼠标移动监听的问题。隐藏画布移出键盘焦点顺序；所有模式及场景按钮带 `aria-pressed`。
- 雪地和云层是程序化的二维交互近似；雪球不做刚体碰撞，云层不做流体求解。状态保存在当前页面会话，刷新后重置。

## 验证

- 单元测试：35 项，含雪痕连续性与局部性、雪深边界、飘雪覆盖、雪球选择 / 增长 / 上限、云隙恢复、聚云方向、风向与减少动态效果，以及全部水面和落石回归。
- 包检查：15 个离线静态文件；经典脚本、DOM 绑定、能力限制、CSS 基线与 WebGL 降级检查。
- 浏览器：Edge 154.0.4258.53；390 × 844、1440 × 960、320 × 568、844 × 390 四种视口。雪痕、脚印、雪球、拨云、聚云、送风、天气、声音开关、三种光照、重置、切换保留、旋转、多点触控取消、隐藏暂停均通过。
- 水面原有浏览器回归通过：水波、浮叶、冰霜、落石、岸边白沫、触摸、光照、声音、重置、安全区、上下文丢失 / 恢复和动态降级。
- `file://` 离线入口无 HTTP 请求；模拟无 WebGL、无 PointerEvent 及减少动态效果时两种新场景仍可交互。浏览器运行错误为零。
- 证据：`evidence-v1.9.0/nature-browser-report.json`、`evidence-v1.9.0/browser-report.json`，以及该目录内的雪地和云层截图。

代码使用 ES2017 / Chrome 61 基线，CSS 使用 Flex margin 与安全区回退，资源均为包内经典脚本。未增加 Native 能力、网络、Worker、WASM 或媒体文件。Android 8.1 / Chrome 61 CSS 兼容性、iOS 小红书 WebView、真机音频听感及性能未实测。
