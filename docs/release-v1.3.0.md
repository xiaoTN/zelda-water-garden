# 水之庭 v1.3.0 · 透明薄冰

2026-10-03。根据“冰太假”的反馈，检索真实摄影，实际检查三张冰面 / 碎冰参考后重做冰材质，详见 [参考对照](ice-reference-study-v1.3.0.md)。

移除均匀的蓝色多边形分格和雪花状大轮廓，改成透出砂石与水色的连续灰青冰层。细裂缝有不同长度、深度和白色断面，局部叠加霜雾和气泡；破口边缘有明暗厚度，碎片改成低抛、翻转的不规则透明薄片。踩碎前的裂纹传播约 180 ms，裂纹最多留存 5 秒。

原有冰霜交互、整池冻结、融冰、滑动冰径、浮叶固定、尺寸变化 / WebGL 恢复保留冰层均保留。非冰区域的水面渲染公式保持原样。

## 预算

冰纹理最长边 1024，使用 CLAMP_TO_EDGE，兼容 WebGL 1 非二次幂纹理；不生成 mipmap，不平铺重复。最坏 1024×1024 RGBA8 为 4 MiB，所有纹理合计低于 9 MiB。默认 DPR / 像素预算、1 draw call / 2 三角形、动态降档、隐藏暂停和 Canvas 2D 兜底仍在。裂纹轨迹在交互时生成，兜底轨迹在初始化生成。
