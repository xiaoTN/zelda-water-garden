# 水之庭 v1.9.13 · 雨势连续过渡

小雨、中雨、大雨与暴雨之间切换时，保留正在下落的雨点和水面波纹，不再清空雨点并重新生成位置。雨量、下落速度、雨丝长度、风偏、阴云与新雨滴的水纹大小，用一秒的缓入缓出逐渐变到目标雨势。

过渡期间再次切换，会从当前显示的中间状态接续；重复选择当前雨势保持降雨连续。已有闪电与对应的延迟雷声自然完成，小雨继续保持无新闪电。雨声沿用上一版的连续音量与音色过渡，短音效保持直接播放。

停雨继续停止新增雨点，平静按钮立即清除天气与波纹。粒子容量、各雨势最终密度、暴雨两倍水纹半径及低档/减少动态效果的工作量限制保持一致。验证证据与发布清单见 `docs/evidence-v1.9.13/`。Android 8.1 / Chrome 61 与 iOS 小红书 WebView 的真机音频、视觉和性能尚未实测。
