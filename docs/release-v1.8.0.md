# 水之庭 v1.8.0 · 刚体落石

工具栏新增「落石」。选中后轻点水面指定位置，随机大小和形状的三维石头从画面顶部上方出现，重力加速下落；落点阴影逐渐收拢，接触水面时才激起宽水波并播放开启状态下的水声。入水后减速，沉到池底并留在场景中；撞击冰面会先破冰。小石头可能完全浸没，大石头可能露出顶部。

新增石头复用场景的深度检测和水深材质。接触水面与落定时更新高度图及障碍格，运动期间最多每 250 ms 更新一次，石面持续影响浅水颜色、泡沫边界和波浪传播；保留水面模拟本身的格点近似。

允许在同一位置重复落石，包括点击已有石头和连续快速点击。使用离线 Cannon-es 0.20.0 刚体引擎：重力、质量、三轴旋转、凸包碰撞、摩擦、回弹、休眠和碰撞唤醒。石头会互相推开、翻滚、堆住或倒向旁边，结果由碰撞求解决定。采用 1/120 秒固定时间步、每帧最多 10 个子步，暂停不补算。动态石头的绘制面与碰撞凸包一致；岸边石头使用其几何凸包，池底采用高度场并用共面平底消除网格接缝抖动，场景边界防止物体离开地形。

水中以浸没比例施加阻力和近似浮力，石头密度按水的 2.65 倍处理；水波仍为浅水高度场效果，不是完整三维流体求解。冰面沿用已有碎裂视觉和波场遮罩，没有把每片碎冰升级为刚体。

最多保留 10 块新增石头；「平静」清除新增石头、取消尚未完成的下落并恢复原始池底。横竖屏切换、降档和上下文恢复保留石头及堆叠状态；页面隐藏时下落暂停。Canvas 兜底也显示下落与落定过程，使用简化表面着色。

新增 `falling-stones.js` 和 `physics.js`，静态包为 13 文件。物理依赖固定版本，通过 `npm run physics` 或构建命令打成 Chrome 61 / ES2017 classic script；引擎 MIT 许可保留在文件头，运行时不联网。新增几何合批绘制：凸包最多 26 三角形 / 块、悬空阴影 12 三角形 / 块，最多增加 380 三角形、2 次 draw call。不在动画帧回读 GPU。新增石头不会恢复拨水的细圆圈或飞溅粒子。

验证包含随机尺寸、加速及旋转、入水事件、池底防穿透、同点连续投放、碰撞动量传递与休眠唤醒、30/60 FPS 固定步长一致性、10 块连续投放稳定性、清除中断和数量上限；浏览器检查空中阶段没有水波、撞击才产生水波、落定更新水深、重复落石可滚动、旋转保留、冰面撞击和 Canvas 降级。证据目录 `docs/evidence-v1.8.0/`。真机 WebView 性能未实测。
