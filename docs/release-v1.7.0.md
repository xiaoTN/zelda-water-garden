# 水之庭 v1.7.0 · 三维池岸与石头

将 WebGL 场景中的贴图石头替换为 144 块独立生成、合并绘制的低多边形石头。池底与岸地改为有高度的地形网格，水面、石头和岸地使用同一个正交相机与深度缓冲。先绘制不透明地形、接地阴影和石头，再以深度检测绘制半透明水面：露出水面的石头保持干燥颜色，水下部分透出水色，冰封后石头顶部仍露出。

石头带面法线光照、湿润底部与轻微顶部苔色。点击可见的干燥石面不会触发拨水。沿岸白纹联动、抗锯齿、滑动宽白色波峰及无细圆圈、无飞溅水滴的行为保留。相机继续固定俯视，草叶与蕨类仍绘在地形材质上；Canvas 降级保留平面石头。

新增 `terrain.js`，交付为 11 文件。正常档 12,800 个地形三角形、3,024 个石头三角形、1,728 个阴影三角形，加上最多 32,768 个水面三角形与背景 2 个三角形，总计不超过 50,322，每帧 5 次 draw call。低档减少地形和水面网格；纹理、DPR、像素预算不增加。GPU 资源统一释放，保留降档和上下文恢复。

验证包括几何高度、法线、预算、干燥石面命中；浏览器通过对实际石头按高度标色，比较绘制水面 / 冰面前后的像素，检查干燥顶部不被覆盖、水下表面受水色影响。证据在 `docs/evidence-v1.7.0/`。真机性能未实测。
