# 海拉鲁自然交互 v1.11.15 · 水波荡漾录音

水波声音随实际波场持续播放。手指停止移动或离开水面后，滑动水流录音继续按原有方式淡出，新的荡漾录音随余波保留并逐渐减弱。轻点、长按、落石、游鱼和雨滴在同一波场中产生的水波均参与声音强度计算。

使用波场高度与相邻模拟帧变化的均方根强度，按网格数量归一化；水波越多、越强，目标音量越大。极微小的波动低于听觉阈值后开始有限淡出并回收声源。始终复用一个循环声源，起音与增强使用约 0.54 秒渐入，减弱使用约 0.72 秒平滑响应，停止时约 0.65 秒收尾；这些是指数包络的响应时间而非固定时长截断。淡出期间新波到来会在同一个声源上恢复音量。

用户提供的约 8.011 秒双声道 MP3 完整保存在 `assets-source/audio/water-ripples.mp3`；来源与校验值见该目录 README。离线运行资源为 `src/water-ripples-asset.js`，完整原始字节由 Web Audio 解码。运行时首尾交叉淡化 120 毫秒，原文件保持完整。轻点与落石的单次录音保留直接起音。

静音、平静和场景切换会淡出水波音频，隐藏页面立即停止并释放；回到水面后仅根据当前波场恢复声音。录音无法解码时保持其他交互和声音可用。
