# 水之庭 v1.9.10 · 轻点水滴录音

轻点水面和放置浮叶使用用户提供的水滴录音，在松手确认轻点后播放。滑动使用连续拨水声；长按释放与落石保留原有较强水声。默认静音，开启“声音”后播放，静音、平静和隐藏页面立即停止短音效。

原始素材以 `assets-source/audio/water-tap.mp3` 保存，5,686 字节，约 0.608 秒。按离线包类型清单将小样本生成为 `src/water-tap-asset.js`，首次开启音效时 Web Audio 解码一次，之后复用同一缓冲，最多四个同时播放的短音效。解码失败回退到原有合成轻点声；解码期间的待播放轻点可被静音或重置取消。

用户对后续资源自行命名和放置的授权已记入项目 `AGENTS.md`；素材来源、名称与运行产物映射记在 `assets-source/audio/README.md`。

验证记录见 `docs/evidence-v1.9.10/`。Android 8.1 / Chrome 61、iOS 小红书 WebView 的真机音频、视觉与性能尚未实测。
