# 水之庭 v1.9.11 · 滑动水流录音

手指滑动水面时使用用户提供的水流录音，替换合成噪声和气泡声。原始素材保存在 `assets-source/audio/water-swipe.mp3`，52,763 字节、单声道、22,050 Hz、约 6.5 秒；生成 `src/water-swipe-asset.js`，离线播放不请求网络。

首次开启声音时解码一次，将尾部与开头交叉淡化 120 毫秒，形成约 6.38 秒的循环缓冲。每次持续滑动只保留一个循环声源和一个音量节点，音量随手速平滑变化；手指静止 90 毫秒后开始淡出，最后移动后 400 毫秒释放声源。松手立即开始淡出，静音、重置、尺寸变化和页面隐藏停止播放。解码完成时仅接续仍在移动的手指，取消或过期手势不会重新播放。解码失败保留水面交互并停止滑动音效。

轻点继续使用之前提供的水滴录音，长按、落石、雨声与雷声沿用现有声音。完整验证记录见 `docs/evidence-v1.9.11/`；Android 8.1 / Chrome 61 与 iOS 小红书 WebView 的真机视觉、音频和性能未实测。
