# 手机顶部间距调整

手机竖屏（宽度不超过 600px）标题与光照按钮整体下移 12px：顶部基础间距由 25px 改为 37px，继续叠加容器或设备安全区。短屏布局沿用现有覆盖规则。

修改时的历史验证（v1.12.0）：

- `npm run build` 通过：99 个测试通过、包检查通过、目录和 ZIP 审计通过。ZIP 共 30 个文件，1,965,304 字节。
- Edge 无头浏览器检查 390×844、320×568、1440×960、844×390；标题和光照按钮均未与场景切换按钮重叠。手机分别注入 59px、44px 顶部安全区。
- 390×844 截图见 mobile.png，位置测量见 layout.json。
- 本次未在真机及 Chrome 61 上实测。
