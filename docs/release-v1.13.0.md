# v1.13.0 — 柔和拨云

手指滑动时拨开更宽的云隙，并把周围的云横向推往四周。松手后位移逐渐衰减，云隙柔和回拢；轻点、停留仍不产生拨云效果。

- 开口半径从屏幕短边比例 0.0288 增至 0.065，约为原来的 2.26 倍。外推覆盖半径为 0.18，采用边界导数为零的羽化曲线，横竖屏保持世界空间中的圆形作用范围。
- 连续云材质及真实 WebGL 高度几何使用同一横向位移。复用已有纹理的 B/A 通道，未增加纹理、网格或绘制调用。CPU 射线拾取匹配 GPU 的八位编码和双线性采样。
- 云层仍不生成雪地式的堆边；开口下凹系数从 0.62 降至 0.12，让透明度与横向流动承担主要表现。外推强度有界，释放后连续衰减，重置会清空位移。
