# 海拉鲁自然交互 v1.12.1 · 脚印踩碎雪球

选择「脚印」后，轻点雪球或拖动经过球面会踩碎雪球，留下鞋底脚印。其他模式仍可拖动雪球，选择脚印模式本身不会清除雪球。

踩碎使用相机射线命中的真实球体，将雪球体积摊回同一份三维雪面高度场，在球心附近堆起平滑碎雪，再压下脚印并将压出的材料推到边缘。堆积根据球大小、网格单元面积及现有雪面高度分配；靠近场地边缘或已有高雪堆时扩展可容纳的范围，保持高度有界及碎雪体积。踩碎后的球不能被旧指针继续滚动或重复摊雪。

复用现有雪面网格、平滑高度、光照、深度与拾取，没有增加纹理、几何或绘制调用。四种视口、两档质量和俯视 / 斜视验证触摸轻点与鼠标拖动、真实雪面隆起、鞋底凹痕、其他雪球保留及离线触摸回退；原有滚雪球、碰撞合并、场景切换、重置与上下文恢复继续回归。
