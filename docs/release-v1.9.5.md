# 水之庭 v1.9.5 · 消除鱼身硬色块

用户截图中的矩形色块来自鱼身整面材质槽：相邻网格面分别使用底色和高对比花纹色，水下覆盖将其染成青灰色硬块。鱼身每个三角形使用独立面法线，也加重了拼接感。固定姿态对照将花纹槽暂时改为底色后，大块边界消失，证实主体原因；水面深度材质无需修改。

鱼身现使用绑定到共享顶点的连续背腹渐变，保留三种柔和配色。颜色在初始化时计算，摆尾时与原有 Blender 皮肤一起运动。法线在形变后按共享顶点累积面积权重，平滑连接鱼身各面；鱼鳍和眼睛保留各自的面法线、材质。Canvas 降级使用同一顶点颜色并取面内平均，减少分块明暗。几何、骨骼动画、鱼群行为及鱼身参与的水深计算保持原实现。

固定缓存新增约 13.5 KB，不增加纹理、网格三角形或 WebGL 绘制次数。制作源说明明确区分原始 Blender 材质与网页运行时配色。

回归测试通过实际 `FishSchool.geometry()` 输出检查三种配色、五条鱼和三个动画时刻的共享顶点颜色与法线连续性，同时检查单位法线和渐变颜色变化。修复前该测试失败；共享顶点的最大颜色差约 0.823、法线差约 1.367；修复后同顶点无接缝。固定姿态截图见 `fish-material-before.png`、`fish-material-uniform.png`、`fish-material-after.png`。

验证完成：47 项单元测试、四视口 29 个浏览器场景、包检查、构建、源目录审计、ZIP 字节一致性与 Python ZIP 内容审计通过。Edge 154 浏览器错误数组为空，审计 0 警告。固定姿态的修复前后近景对照确认硬色块已消失，三种配色、摆尾、鱼群交互及统一水下材质继续保留。证据目录：`docs/evidence-v1.9.5/`。
