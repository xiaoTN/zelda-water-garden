# v1.16.0 — 小巧的折纸船，跟随指尖转向

纸船重做为传统折纸样式：两端尖起，船舷围出开放的船舱，中央竖起三角折面，薄纸边与内外纸面使用真实 WebGL 几何。默认长度比初版缩小约 23%，纸色改为柔和的暖白；折面使用世界法线与方向光，随晨光、暮色和月夜变化。没有新增贴图或外部素材。

拖动时船头跟随手指方向，甩出后朝着惯性速度方向滑行。方向与速度从同一水面相机平面上的指针位移计算，水波引起的升降不会改变手势方向；不足 0.6 像素的指针抖动不触发转向。船身位置仍通过相机射线与实际起伏水面求交，抓取仍检测真实折纸网格三角形。

移动和转向一起分步检测真实船身轮廓，转向选择较短的角度路径，避免急转时扫进石头、岸边或其他纸船。被障碍挡住的移动不累加对应甩动力；松手时若无法转到惯性方向，就停在安全位置。保留速度上限、水面阻力、停顿后不甩出、取消与场景退出停止运动，以及拖动/滑行产生水纹的行为。

每艘 56 个船体三角形和 2 个阴影三角形，最多十二艘共 696 个三角形，仍只增加 2 次 draw call。模型与阴影缓冲复用既有固定容量，不增加几何数量上限；普通和低档均渲染同一真实折纸模型。
