# 海拉鲁自然交互 v1.12.0 · 滚雪球与碰撞合并

「雪球」改为「滚雪球」模式。点击按钮只选择模式，轻点或按住雪面不会直接生成雪球；手指或鼠标滑动后才从零半径开始聚雪，随着实际移动距离逐渐滚大。松手留下雪球，下一次在空白雪面滑动可以滚出新的雪球，也可以直接拖动已有雪球继续滚。

雪球接触时合并，合并半径按两球半径立方之和开立方计算，保留总体积并支持连续合并。碰撞以渲染时相同的三维球心、半径与雪面支撑高度判断；快速滑动也检查经过的路径。合并后继续拖动不会缩小，已被合并的旧雪球不会通过另一根手指重新出现。

复用真实 WebGL 球体网格、材质、世界空间光照与阴影，保持雪面接触、深度遮挡和相机拾取。场景同时保留最多 12 个雪球，符合既有 12 球阴影预算；达到容量时保留所有雪球，合并腾出空间后可继续滚出新的雪球。默认档满场 98,624 个三角形，低档 38,472 个，均为 14 次绘制（含雪面与飘雪）。

验证包括模式点击与轻点不生成、鼠标和双指滚动、多雪球保留、体积合并、不同高度球体接触、快速划过碰撞、旧指针失效、两档满场几何预算与拾取、雪面支撑、切换与尺寸变化、上下文恢复及离线运行。
