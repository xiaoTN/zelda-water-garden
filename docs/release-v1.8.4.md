# 水之庭 v1.8.4 · 更宽阔的落石水波

石头入水时激起明显大于手划的水波。扩大实际波场的受力面积，由现有水面网格起伏、折射和波峰材质表现向外传播的波浪；波纹随石头尺寸增长，小石头也有足够宽的冲击范围。

## 效果

- 中央扰动强度由 0.75 增至 0.95，半径由石头半径的 0.45 倍增至 0.85 倍，并保留 0.045 的最小波场半径。
- 外围 16 个扰动点向外移至石头半径的 1.5 倍，强度由 0.24 增至 0.5，单点半径至少 0.035，让波峰更宽、更连续。
- 落石效果全部由模拟波场驱动，不增加外围描线、额外绘制圆环或飞溅水滴。
- 保留波场对池岸、出水石头和冰层的阻挡，以及原有手划效果、落石碰撞和休眠逻辑。仍在实际入水时触发，一次入水产生一次冲击，不产生飞溅水滴。

## 验证

新增行为回归在 0.38、0.462、1、2.2 四种宽高比下，对比最小石头与最大强度的单段手划：初始水波在垂直于划动方向上的宽度超过 3 倍，前半秒累计波场能量超过 4 倍，大石头的初始能量超过小石头的 2 倍。这是数值波场比较，不能等同于实际水体的物理能量或真机性能测量。

另有回归覆盖已有石头遮挡落点中心的情况：中心不能注入波纹时，外围仍推动周围水面；干燥网格保持无波浪，防止连续落石时漏掉冲击。
