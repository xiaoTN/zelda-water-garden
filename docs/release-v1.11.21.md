# 片刻 v1.11.21 · 唯美自然文案

界面以「片刻」为名，三个场景分别呈现「水光、雪落、云间」，移除原有海拉鲁与 HYRULE 的名称及英文副标题。页面标题、主区域的无障碍名称随场景一起更新。

- 水光：风过水面，留下一点温柔。
- 雪落：雪落无声，时光也轻了。
- 云间：天光轻落，云影缓行。

加载文字改为「慢下来，风景正在醒来…」。拨水、浮叶、落石、划雪、雪球的操作提示与降雨提示采用轻柔的自然表达；操作按钮保留清楚、简短的名称。README 的介绍和项目描述同步采用新的文案。此版本只调整文案，保留现有三维场景、交互及声音淡入淡出行为。
