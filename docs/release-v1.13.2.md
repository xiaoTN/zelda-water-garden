# v1.13.2 — 风景切换的薄雾过渡

水光、雪落、云间切换时，先用一层轻雾柔和遮住当前实机画面，在完全遮住的时刻切换场景，再缓缓显现下一处风景。标准时长为淡出 280 ms、淡入 560 ms，使用平滑曲线；减少动态效果偏好下缩短为 100 ms、160 ms。雾色分别适配晨光、暮色、月夜。

过渡仍使用原有实时 WebGL 世界，不截屏、不同时模拟两个世界、不改变几何或相机。场景选择按钮持续可用；快速改选从当前遮罩透明度继续，未展示的中间场景不会闪现。过渡期间清除旧手势并暂停世界触碰，结束后恢复。标题、玩法、画布和选中场景在遮罩完全不透明时同步切换。

开始切换时旧交互音效与雨声柔和淡出，背景音乐保留原有场景混音衔接；切换回水面时恢复当前雨势和有效水纹声音。切换途中不触发新的落石或雷声音效。退到后台时完成最后请求并收起遮罩，重新进入无需等一个残留动画；调整窗口继续过渡，渲染中断时收起遮罩以显示真实恢复状态。
