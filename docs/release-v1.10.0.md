## 对应改动

- 两种场景新增真正位移的 WebGL 网格。雪和云共用表面渲染器，但使用不同的起伏幅度、局部压陷方式与阴影色。
- 云层由连续的多尺度圆润起伏构成，拨云压低局部高度形成云间通道，聚云恢复并抬高局部表面，送风与微风驱动云材质平移。云沟缓慢回填，压到边缘的云体形成隆起。
- 雪地改用具有压实底面和较陡侧壁的笔刷剖面，边缘保留排开的雪。相交轨迹合并，未开启飘雪时持续保留。脚印、滚雪球与长按压实仍可用。
- 顶点根据高度场计算法线，晨光、暮色与月夜调整表面受光。使用高度投影对触点作近似反算，使拖动位置和表面路径对应。
- 上一版的 Canvas 2D 画面保留为降级：WebGL 不可用、缺少顶点纹理、上下文丢失或持续慢帧时继续提供交互。

## 离线与性能设计

新增 `nature-surface.js`，无新运行依赖、外部纹理或视频素材。程序生成 256 × 256 的双通道高精度起伏纹理，交互纹理为 320 × 320。默认 48,841 个顶点、96,800 个三角形、1 次绘制；低档 21,025 个顶点、41,472 个三角形。画布沿用 DPR ≤ 1.5、像素 ≤ 200 万，低档 DPR 1。两张表面纹理合计约 0.64 MiB，未使用 WASM、Worker、网络请求或帧内 GPU 同步回读。

未显示的场景停止模拟；页面隐藏暂停 RAF 与音频。纹理和缓冲复用，交互纹理只在变化后上传。新增云材质在减少动态效果模式下停止自动漂移，仍响应用户直接送风。

## 验证记录

自动化结果保存于 `evidence-v1.10.0/`。测试覆盖既有水面回归、新场景四种视口、真实 WebGL 渲染路径及三角形预算、云海高度场变形、云沟回填、雪痕保留、风向、光照、旋转、多点触控、页面隐藏、离线文件入口和真实 WebGL 上下文丢失后的可交互降级。构建另执行单元测试、包检查、目录审计、ZIP 内容比对和体积审计。

本次结果：37 项单元测试通过；Edge 154.0.4258.53 的 390 × 844、1440 × 960、320 × 568、844 × 390 四种视口通过，浏览器错误为零；完整水面回归通过。16 个静态文件的包检查、目录及 ZIP 审计均通过且无警告。最终 ZIP 为 447,923 字节，SHA-256 为 `13d24901b269cf0a81732d9d2c8265748bd55e8bc714f1ea4dade68c5142ad51`。

这是一套适配离线 H5 的高度场近似，没有移植视频中的 Unity 工程或角色模型，也不是完整体积光线步进云或雪粒子物理。光照由表面法线和局部遮蔽近似得到；Canvas 2D 降级视觉更简化。Android 8.1 / Chrome 61 CSS 兼容性、iOS 小红书 WebView、真机性能与音频听感未实测。
