# v1.15.1 — 三场景共用水光背景音乐

水面、雪地和云层统一使用水光音乐。首次操作后温柔淡入，整段录音沿用既有循环接缝处理持续播放；场景切换、快速来回切换均保持同一音乐声源、音量和播放进度。音乐仍直接连接公共主输出，交互水声、雪声等继续按场景淡出淡入。

退出或隐藏页面释放音乐声源，回来后恢复水光音乐；保留浏览器暂停、打断恢复、用户手势重试和关闭上下文重建逻辑。首次播放和隐藏后恢复继续沿用前半段随机进入。雪地、云层的旧背景音乐编码文件及 HTML 引用从发布包移除；打包脚本也只输出水光音乐，原录音、优化录音和来源记录全部保留在 `assets-source/audio/`。
