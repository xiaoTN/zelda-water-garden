# 海拉鲁自然交互 v1.11.19 · 滑动云海

云层场景移除底部「拨云、聚云、云海」工具栏，操作提示简化为「滑动拨开云海」。移动手指或鼠标时直接拨开云层，停下后间隙自然回拢；轻点、按住不动、同一位置的移动事件和空格 / Enter 不触发云层交互。

取消云层的模式选择、聚云、重置入口及持续按压处理；隐藏的共用按钮也不能改变云层模式或清空云海。水面与雪地使用原有工具栏，切换回来能继续操作。场景音效淡入淡出保留，云层短音效随滑动触发。

验证覆盖四种视口、真实指针滑动、静止与按压无交互、隐藏按钮无副作用、旧触摸事件路径、离线运行、多指取消，以及 3D 几何、相机拾取、两档预算和上下文恢复。上传包为 `artifacts/zelda-water-garden-minitool-v1.11.19.zip`，26 个离线文件；记录见 `docs/evidence-v1.11.19/`。
