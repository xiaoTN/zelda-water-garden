# 海拉鲁自然交互 v1.11.19 · 微弱水纹提前静音

水声随水波变弱，在水纹已经很小时柔和淡出并停止。水面上剩余的微弱波纹继续自然消散，不再等待波纹完全消失才停止声音。

以实际水面高度与运动的 RMS 强度判断声音：低于或等于 0.004 时开始淡出，保留原有 0.12 秒音量时间常数，并在 0.65 秒后释放循环声源。重新起音需要强度超过 0.006，避免微弱残波在临界值附近反复触发声音；新的明显水波可以平滑恢复播放。强波仍随强度变化并保留原有最大音量，轻点、滑动、落石录音与场景切换声音维持原有行为。

验证覆盖微弱波纹静音、临界值波动、淡出期间重新拨水、两种水面网格上的自然衰减，以及真实 WebAudio PCM 的连续音量包络。离线上传包为 `artifacts/zelda-water-garden-minitool-v1.11.19.zip`，验证证据保存在 `docs/evidence-v1.11.19/`。
