# v1.16.3 — 从看得见的小雪球开始

新滚雪球手势在开始滑动约 3 像素后，生成具有初始大小的真实球体，再按实际滚动路程积雪、慢慢长大。初始半径默认 0.025，乘以视口宽高比与 1 的较小值，保持手机竖屏与横屏下适合视口短边的大小。选中模式、轻点或仅按住仍不生成球。

本机面板新增一行“初始半径”，范围 0.01–0.05，实时影响随后新生成的雪球；已有球保持原来的半径。保留用户选定的生长速度 0.035、减速摩擦 4.6、甩动触发速度 3.8，以及纸船大小 0.6。即使生长速度设为 0，也能从一个可见球体开始推动。

球体模型、世界空间接触、滚动旋转、雪痕、合并体积守恒、惯性和运动录音继续使用现有实现，最多十二个球，不增加单球几何或 draw call。初始球体创建通过 `Snow.startBall` 统一读取参数；用于几何与物理验证的显式半径创建接口继续保留。

验证记录与关键截图在 `evidence-v1.16.3/`，日志和额外截图保存在已忽略的 `tmp/`。

`npm run build` 通过：118 个单元测试、32 文件包检查、离线能力与兼容性审计、ZIP 结构和源码字节核对，零审计警告。单元检查覆盖可见初始球体、静止不增长、实际路程增长、视口比例、初始半径只影响未来球体，以及零生长速度下仍有可见球体。

`node scripts/snow-inertia-check.cjs`、`node scripts/nature-browser-check.cjs` 和 `node scripts/render-recovery-check.cjs` 均通过：普通/低档、四种视口、最初 4 像素滑动生成可见球体、真实网格抓取与接触合并、惯性和录音、实时初始半径与保存/恢复默认、原生触摸、离线容器排除面板及上下文恢复。使用 Edge 154 软件 WebGL；小红书真机容器尚未实测。
