# 片刻 v1.11.24 · 落稳的石头固定在原处

石头落稳后，将原来的动态刚体转为静态碰撞体，保留相同的凸包、位置和四元数朝向。后来落下的石头仍能碰撞、翻滚并停在它旁边或上面，但不能再推动已经落稳的石头。移除最早一块石头也不会唤醒其余固定石头；旋转屏幕后保留固定状态与朝向。

落稳判定要求碰撞组获得支撑，并在低运动状态持续约 0.7 秒。对接触求解器偶发的速度脉冲做 0.15 秒平滑，支撑判定允许最多 0.06 秒的接触间断，避免凸包边缘微小抖动导致持续无法落稳；空中无支撑或持续滚动的石头继续参与物理模拟。

固定石头不再计算浮力、阻力、积分与动态位置同步，也不再重复更新水深版本。所有石头都固定后，跳过落石物理世界的步进；有新石头投入时恢复模拟。固定石头之间不再做碰撞求解。保留最近 10 块石头、入水声音、水波、鱼群避让和「平静」清空行为。
