# 仓库文件归档

长期资产和可重现项目所需的文件提交到 Git，临时输出统一放在根目录 `tmp/`。此目录已被忽略，按用途分子目录，例如 `tmp/experiments/`、`tmp/browser-evidence/`、`tmp/archived-logs/`。临时脚本、试验结果、抽帧、大量重复截图和构建日志放在这里；可复用的正式脚本仍放 `scripts/` 并提交。

| 内容 | 位置 | Git 管理 |
| --- | --- | --- |
| 运行源码、测试、构建脚本及依赖锁文件 | `src/`、`tests/`、`scripts/`、根目录 | 提交 |
| 原始素材、图标和封面设计候选、来源说明 | `assets-source/` | 提交，保证后续选择和复用时素材仍可找回 |
| 发布说明、关键截图、测量数据和审计证据 | `docs/` | 提交，保留验证发生时的版本信息 |
| 临时脚本、一次性诊断、抽帧和完整检查日志 | `tmp/` | 忽略 |
| 可重新生成的上传 ZIP 和构建目录 | `artifacts/`、`dist/` | 忽略，沿用项目规定的位置 |
| 本机依赖、Python 缓存、环境变量与编辑器设置 | `node_modules/`、`__pycache__/` 等 | 忽略 |

视频编辑器的 `scripts/promo-video/public/audio/`、`fonts/`、`frames/`、`media/`、`stills/` 已由该子目录的规则忽略，是当前预览读取的本地运行材料；保留这些固定路径。未来的一次性分析输出应直接写入根目录 `tmp/`。

本次归档将两组发布图标候选（七张 PNG，附来源和验证记录）及手机顶部间距修改、四份历史验证文件纳入 Git。它们是长期素材和修改证据，不属于临时文件。散落在 `docs/water-ripple-history/evidence-v1.11.19/` 至 `evidence-v1.11.21/` 的九个旧 `.log` 移到 `tmp/archived-logs/docs/water-ripple-history/`，按原相对路径归档。没有删除素材或日志。

不按 `.png`、`.json`、`.mp3` 等素材后缀统一忽略，以免把源码资源和验证证据一起隐藏。
