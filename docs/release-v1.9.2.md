# 水之庭 v1.9.2 · 俯视降雨与密集雨纹

修正雨丝沿屏幕统一向下移动、与俯视水池不一致的问题。每个雨滴保存自己的水面落点和离水高度；高度降低时，投影从镜头附近向落点收拢，四周的轨迹方向随位置变化，画面中心附近呈短雨点。到达水面时投影和雨纹中心重合。雷电表现为照亮场景的环境闪光，取消侧视天空的折线闪电，雷声与频率联动保留。

旧版暴雨预算虽为每秒 68 次，但每帧最多只留两个落水名额，名额还被落在岸上的雨点消耗；水纹存活仅 0.65 秒，并与手指涟漪共用 48 个圆环的容量。现改为按秒累计有效落水预算，仅接受水域、非完整冰面及可用水面网格的落点。空中雨滴真实落地后才触发雨纹。

| 雨势 | 默认空中雨滴数 | 每秒有效落水上限 |
| --- | ---: | ---: |
| 小雨 | 48 | 20 |
| 中雨 | 112 | 65 |
| 大雨 | 240 | 160 |
| 暴雨 | 420 | 320 |

雨纹使用独立的 384 个对象池，存活 0.9–1.2 秒，以细小、较淡的近圆形涟漪覆盖水面，按年龄分组绘制。低档雨滴数为 40%，最多保留 144 个雨纹，落水预算也降为 40%。昂贵的波场扰动另限默认每秒 110 次、低档 44 次，扰动半径缩为 0.01；避免把雨纹密度直接变成同等数量的大范围波场计算。已经合入的落石冲击和连续投石逻辑保持不变。

停雨让已有雨纹自然消退；平静和一键冰封清理雨纹，调整视口后重新生成适配当前画面的雨纹。所有对象池有固定上限，不新增纹理或外部资源，静态包仍为 14 文件。

新增回归检查俯视投影在四个象限向落点收拢、零高度落点误差，以及每秒 60、30、12.5 次更新时暴雨密度不再被“两次每帧”限制。浏览器在真实水池中测量暴雨落水计数和存活雨纹数量，并保存 `mobile-topdown-storm.png`。

验证完成：37 项单元测试、四种视口浏览器回归、包检查、构建、目录审计、ZIP 字节一致性核对和 Python ZIP 内容审计全部通过，浏览器错误数组为空，审计 0 警告。390×844 暴雨用例等待约 1.8 秒后记录新增 602 个有效落水点、338 个存活雨纹；该计数含浏览器采样调度时间，用于验证实际画面密度，不是帧率或真机性能指标。
