# 水之庭 v1.9.12 · 长声音柔和过渡

滑动水流声柔和淡入，松手、静止、切换玩法与重置时渐渐淡出，约 650 毫秒后释放声源。淡出期间继续滑动会沿用同一个循环声源，从当前音量平滑接回。录音首尾的交叉淡化继续保留。

切换小雨、中雨、大雨和暴雨时沿用同一条雨声，音量与音色平滑变化。停雨和取消雷声时留下约 700 毫秒的淡出尾音；关闭声音会等尾音结束后暂停音频，快速重新开启会取消暂停。页面隐藏时立即释放声音并暂停。轻点水滴与其他短音效保持原有起音和自然衰减。

用户的声音过渡偏好已写入 `AGENTS.md`，后续接入长音频时继续遵循。原始录音与离线素材保持不变。验证记录、音频渲染测量、构建日志及发布清单见 `docs/evidence-v1.9.12/`。Android 8.1 / Chrome 61 与 iOS 小红书 WebView 的真机音频、视觉和性能尚未实测。
