# v1.11.10 — 拨云深度与回卷

- 保持拨云范围，使用指针移动距离和时间估算速度。快速划动更快打开深空隙，慢移和静止接触仍渐进推开云层；插值采样共享实际手势速度，避免把采样数量误当速度。
- 云层世界空间位移比例 0.28→0.62，CPU 射线拾取与 GPU 高度一致。透明边缘加入细碎变化，拨开时能看到更深处的大地。
- 用守恒的相邻单元通量交换替代单一均匀衰减：隆起的两侧向空隙扩散，叠加轻微旋动。深空隙恢复较快，剩余云絮缓慢恢复；减少动态效果时关闭旋动，直接交互和回填保留。
- 无新增纹理、绘制调用或三角形。复用固定传输缓冲区（约 1.56 MiB CPU 内存）与一维流场；显式步长限幅避免长帧数值爆炸。真机性能未实测。
