# 本机开发者参数

在 `localhost`、`127.0.0.1` 或 IPv6 回环地址通过 HTTP/HTTPS 打开项目，右侧会出现“开发者参数 · 本机”。宽屏默认展开，窄屏默认收起，点击入口展开。入口适配安全区，不覆盖场景选择。

滑块和数字输入实时生效。“恢复默认”恢复当前版本的全部默认值；设置保存在当前浏览器、当前站点的本地存储中，刷新后仍保留。存储不可用时仍能在本次运行调整。“查看参数”提供可选中复制的 JSON，没有调用剪贴板或下载能力。

每个参数一行，名称、滑条和数字输入并排；按纸船、雪球、雪地、水与云、场景分组，参数区可滚动，在 320 像素宽屏幕也不横向溢出。

文件方式加载的离线小工具、非本机站点，以及注入 `xhs.miniTool` 的正式容器不展示面板，也不读取这些调试设置。本机参数不会自动写回源码或发布包默认值；固化数值时使用查看参数中的 JSON 修改默认配置。

甩动速度以最近约 120 ms 的手势事件和 3D 世界位置估计。最后移动后停顿超过 100 ms 再松手不启动惯性；触摸取消也不甩出。惯性途中再次抓住球会立即停下。滚动沿用球体旋转、雪痕、增长及世界坐标接触检测，合并时守恒体积并合并动量；到扩展雪原边界会停止对应方向的移动。切换场景、退出页面或渲染中断时停止惯性，保留现有雪球位置。

摩擦、触发速度和速度上限使用渲染世界的长度单位，水平坐标仍与同一相机及雪原接触高度一致。默认值位于 `src/garden-tuning.js`，参数变化不增加球体或几何数量。

水面工具栏选“纸船”，轻点宽一些的水面放置；拖动已有纸船不会再生成新船，在拨水、浮叶等模式也可抓取纸船。v1.16.0 默认船身比初版更小巧，大小参数仍以 1 为默认值，缩放薄纸边、开放船舱和中央三角折面的真实网格。

拖动时船头跟随手指，快速松手后沿最近手势方向继续滑行。指针位移按同一相机投影到水面平面，排除随波升降对方向估计的影响；被障碍挡住的移动部分不累加甩动力。转向沿较短角度逐步检查船身轮廓，岸边、石头和其他船也会阻止转向穿越。抓住立即停止，停顿超过 100 ms 后松手不启动惯性。触摸取消、场景切换、页面退出、失焦、尺寸改变及 WebGL 中断停止运动。“平静”清除纸船，刷新页面重新开始。最多十二艘；滑行会留下水纹，并沿用水纹音频的淡入淡出。

v1.16.1 纸船会像浮叶一样顺流漂动。附近拨水沿手指移动方向推动未被抓住的船；实际波场的局部坡度与缓慢环境水流继续推动船身，水流速度与甩出速度独立衰减、一起移动，并沿用船身的转向和扫掠碰撞检测。被抓住时立即清除水流速度、暂停漂动；松手后可重新受水流影响。缓慢漂动轻柔转向，细小波动不频繁改向；被动漂动不会持续生成自己的驱动水波或让水纹声音无限延长。减少动态效果偏好只关闭环境水流，保留主动拨水及波纹推动。
