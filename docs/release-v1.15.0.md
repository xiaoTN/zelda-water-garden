# v1.15.0 — 纸船与紧凑调参面板

水面工具栏新增“纸船”：轻点宽阔水面放船，拖动已有纸船；快速甩动后松手沿最近手势方向继续滑行，随阻力减速，遇到岸边、石头或其它船停止。其它水面模式同样能抓住已有纸船；抓取立即停止惯性，停顿后释放和取消手势不甩出。切换场景、失焦、页面退出、改变尺寸或水面 WebGL 中断停止运动、保留位置；“平静”清空纸船。最多十二艘。

纸船为真实折纸三角网格，二十个三角形构成船壳、内折和立起的中央折痕。与水面共用倾斜正交相机、世界坐标、光照和深度缓冲；以相机射线与船的实际三角形求交，抓取保留指尖与船的偏移。船随同一解析水波和交互高度场升降，并采样邻域产生俯仰与侧倾。拖动和惯性滑行扰动原高度场，沿用已有水流及水纹声音和淡入淡出。

甩动速度取最近约 120 ms 的手势时间与水面世界坐标，不受渲染帧时钟影响。指数阻力采用梯形积分，按小于船长的扫掠步长检测碰撞；船轮廓间使用凸多边形分离轴检测，岸石使用轮廓周边及中心探点。全部纸船网格和柔和投影分别合批，最多增加两次绘制、240 个船体三角形和 24 个投影三角形；复用固定容量顶点区，不增加纹理，无 GPU 回读。

本机面板增加惯性强度、水面阻力、甩动触发速度、最高滑行速度、纸船大小、随波摇晃幅度六项，共十九项参数。每项的名称、滑条和数值并排在一行，可分组滚动；数值实时生效，沿用浏览器存储、恢复默认和 JSON 查看。正式容器、离线入口继续隐藏面板。详见 [调参指南](developer-tuning.md)。
