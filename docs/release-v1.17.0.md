# v1.17.0 — 无边界的全屏水面

基于当前 `main` 的 `726b87f`（v1.16.6）重新实现 HAUM-1 的全屏水面需求，交付任务为 HAUM-3。

移除椭圆池岸、地面植被和环绕池岸的默认石头。整个视口使用同一张有深度、世界空间光照和实时位移的 WebGL 水面网格；水下地形始终保持在水面之下。水面网格向屏幕外延伸 6%，覆盖倾斜相机与波峰、波谷造成的投影变化，水下地形也留有投影余量。

四边与四角均接受拨水和雨滴。触摸使用与纸船相同的相机射线求交，几何遮挡仍在屏幕坐标中判断。游鱼、浮叶、纸船拖动与惯性、水流推动、落石物理、雨天、光照和场景切换保留；用户落下的石头继续影响真实水深、波纹和遮挡。低档减少网格与绘制分辨率，WebGL 不可用时保留明确的恢复状态。

验证详情见 `evidence-v1.17.0/validation.md`，包体与校验和见同目录的 `artifact-manifest.json`。离线 ZIP 位于本地忽略目录 `artifacts/`，通过任务附件交付。
