# v1.11.1 — 划开时向两侧堆积雪与云

旧画笔只提高凹陷值，并且仅在尚未凹陷的单元上添加一圈很浅的凸边。反复划过会覆盖凸边，又不能把材料堆回旧沟槽，最终造成整体下陷的观感。

现在使用有正负高度的材料转移：中心移出的量按权重分配到周围，拖动时优先堆到方向两侧；已划过的单元也能接收材料、被回填或重新堆高。达到高度上限时将余量分配到其他接收单元；周围没有容量时限制继续挖低。重复按住同一点不会无限生成凸起。

雪地保持压实沟底与明显雪脊。云层采用平滑曲线形变，聚云从周围取量并抬高中间；恢复过程对正负高度同比衰减。网格顶点与 CPU 射线拾取都使用同一正负位移比例，堆起部分具有真实世界高度、法线与深度遮挡。过程是高度场材料转移近似，不是完整的颗粒/流体物理；开启飘雪仍会逐步覆盖痕迹。

验证：

- 增加四项回归：沟槽两侧凸起及重复按压、全区域反复扫过、交叉沟槽回填、云层拨开/聚拢/恢复的材料平衡。
- 雪地在竖屏与横屏比例下连续三遍扫满可交互区域，仍保留明显正负位移；所有值有限且在 [-1,1] 内，累计有符号误差低于 0.02 网格单位。
- 新浏览器脚本检查雪、云实际世界高度在单条沟槽和全区域扫过后同时有负位移与正位移；截图与数值报告在 evidence-v1.11.1/。
- 水面完整浏览器回归和雪/云四视口交互检查通过，无页面错误。相机、拾取、上下文恢复与两档资源检查继续通过。
- 最终构建通过：43 项单元测试全部通过，17 个离线静态文件包检查通过，源目录与 ZIP 审计均为 0 警告，ZIP 内容字节一致性验证通过。
