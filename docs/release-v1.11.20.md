# 海拉鲁自然交互 v1.11.20 · 水声更早收尾

水波声比 v1.11.19 更早开始淡出，并更快停止。淡出阈值从 RMS 0.004 提高到 0.006，重新起音阈值从 0.006 提高到 0.008，保留临界强度附近的防反复起音机制。

淡出尾音从 0.65 秒缩短到 0.35 秒，音量时间常数从 0.12 秒缩短到 0.06 秒；水波减弱时的音量跟随时间常数从 0.24 秒缩短到 0.14 秒。声音仍平滑收尾，明显的新波纹可以在淡出期间恢复播放。
