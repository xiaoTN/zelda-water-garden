# 海拉鲁自然交互 v1.11.20 · 云层散开不堆高

修复滑动云海时手指周围出现雪地式凸起的问题。云层局部平滑变薄、散开，周围不再接收中心移出的材料，松手后通过扩散和衰减自然恢复。反复划过、交叉滑动及扫过整个区域都不产生堆高边缘；云团本身的立体起伏与漂移保留。

云层的软高度场仅允许 0–1 的变薄量；绘制前平滑与回拢都保持非负，GPU 的堆高通道为零。移除已无用户入口的聚云实现，避免其他路径重新制造凸起。雪地继续使用材料转移与两侧堆积。

验证包括云层局部和全域重复滑动、回拢无凸起、实际指针交互、默认及低档 GPU 位移、两种相机视角和边缘拾取，并保留场景音效淡入淡出与离线验证。上传包为 `artifacts/zelda-water-garden-minitool-v1.11.20.zip`，26 个离线文件；完整记录见 `docs/evidence-v1.11.20/`。
