# 第四版：转场柔边保持稳定

用户反馈：每次字幕出现时画面周围柔和度突变，具体指出约 4.6 秒切点。

## 原因与修复

旧版 `SurfaceShot` 在每个镜头上应用纵向透明遮罩；两个镜头在 18 帧转场中重叠，两份部分透明边缘合成会比一份更亮。旧镜头在 f138 退出时，从叠加边缘突然恢复单层边缘。字幕在 f134 开始渐入，所以视觉上像是字幕触发。

使用相同冻结画面排除素材运动，直接渲染实际 `SurfaceShot`：f137→f138 边缘平均 RGB 绝对变化 13.8457，最大 37，测试失败。无字幕时同样复现，排除字幕字体或字幕底色为本次突变主因。

将柔边移到独立的 `SurfaceMatte`，先合成两段画面，再应用一次固定边缘。修复后同一检查均值和最大值均为 0。结尾三景图位于柔边层上方，字幕单独保持渐入渐出。工作台清单也加入同一固定叠加层。
