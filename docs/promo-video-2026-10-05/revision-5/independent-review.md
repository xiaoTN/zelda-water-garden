## 独立音频及字号数据

封装探针采用最终 AAC 解码与独立重建的计划 PCM 混音比较。10/19/30/37/42/47 秒均测得 0 样本、0 帧偏移；峰值 −6.309dBFS。与原音源直接核对时：10、30、37、42 秒对应原录屏 PCM 相关约 1，47 秒对应水音乐相关 1。落石段输出 19 秒的 prepared PCM 与原录屏对应 21 秒存在约 897 样本/18.7ms/0.56帧的截取差异，重新对齐后的相关约 0.999643；属于小于一帧的源切片差异，未发现需要阻塞交付的明显偏移，不记为零。

字号测量针对最终 PNG 中接近指定字色的像素，RGB 各通道容差18、每行至少4像素，合并不超过3行的抗锯齿间隙，读取整行墨迹上/下缘。主字 f69 为 y328–411、y432–515，雪字 f1126 为 y328–411、y432–516，云字 f1261 为 y328–411、y432–515；结尾主句 f1440 为 y194–276、y298–381，末问句 y1116–1167，标签 y1030–1079。这个口径包含正常抗锯齿轮廓，未把阴影外延当作字高。

临时独立证据：`tmp/promo-independent-v5/motion-*.jpg` 为最终片精确帧号动态采样；`final-review-measurements.json` 为最终文件 hash、字号与音轨数据。`source-check.json` 保留直接源比较的原始数据，其中落石项未施加偏移，故原始相关较低；本报告注明的 897 样本结果来自后续独立局部搜索。

## 结论与剩余事项

必须修复项：**未发现当前最终成片的可证实阻塞项。** 全屏实机、水优先、雪云各4.5秒、静态三景波纹收尾、预告文案及关键文字安全位置通过。审查期间发现的旧字号/末句边界和 README 文件身份已在最终重渲与文档更新后复核消除。

建议优化项：没有需要立即修改的视觉建议。f1440 的背景原控件仍隐约可见，这是已记录的真实游戏背景；未来新版本可在保留实机要求的前提下进一步简化底部视觉注意力，但不作为本版问题。

无法验证项：A1/A2/A6/A7、S4 的原速听觉气质、SFX 可听性与瞬态听感；30fps 连续原速播放中的高频微抖动和实际转场主观流畅度；真实小红书客户端的 UI 覆盖/缩放、设备颜色呈现；第二次同工程重渲的逐帧确定性；原游戏 WebGL、拾取、上下文恢复与两档质量。这些不能由视频静帧、PCM 相关或代码阅读替代，本报告不将其冒称为已通过。后四项属于视频独立审查的能力或任务边界，不要求为本次纯宣传片修订重做游戏代码。
