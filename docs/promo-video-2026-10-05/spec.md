## 素材与声音

源文件原样复制至 `assets-source/video/`，来源和 SHA-256 在相邻 `recordings-manifest.json`。保留用户下载目录原件。源宽度 740/742、高度 1080；选取中心 740×570 区域（x=0,y=245），雨景进一步裁为 740×510，排除顶部场景开关、提示和底部工具栏。生成片段在工程 `public/media/`，不进入游戏运行包。

使用录屏原声，+5 dB 后淡入淡出；**不叠加新的背景音乐**，也不把含录屏原声的版本称作“纯音效/无 BGM”。若录屏混有原游戏配乐，保持其原始混合关系。源音轨峰值 -9.4 dB，处理后单轨峰值不超过 -4.4 dB，最终混音仍需检测。短促落水声音不逐个施加包络；仅剪辑接缝处柔和交叠。

## 选择与适用范围

使用 video-shotcraft 的 Remotion 工程、真实视频承载思路、可编辑清单和独立终检流程。已检查 ClipCard 源码；本片为矩形原速录屏裁切，无循环，因此采用直接 OffthreadVideo。没有用户指定 Gallery 卡/变体，也没有宣称复刻某个 Gallery 样片；不引入翻卡、发布会合影等与实机水面叙事不符的运动。Gallery/卡片变体还原项为不适用。

有意识不采用 aesthetic-rules 的 S1 强电子鼓点、Q7 资产环绕、Q8 高能结尾、C2 功能口号：用户明确要求唯美宁静，真实水声与柔和收尾优先。素材仅为用户授权游戏录屏，不含私人消息、账号、内部地址或密钥。

本任务仅制作宣传媒体和独立编辑工程，不修改游戏 src/、物理或音频行为。游戏原有门禁与宣传片导出质量分别记录；最终验收见同目录报告。

技术处理：预览使用 H.264，正式渲染使用从相同片段解出的完整 30 fps JPEG 帧序列，逐帧播放，绕过 Windows Remotion 合成器的录屏随机寻帧失败；不是抽几张静帧做幻灯片。Remotion 4.0.484/AAC/48 kHz/MP4 实测输出音频晚 2048 个采样点，统一在 `export.mjs` 对最终混合轨裁去这些垫头并补尾，视频包不重编码。工作台可调整内容；正式交付导出走 `npm run render`，确保同样同步补偿。
