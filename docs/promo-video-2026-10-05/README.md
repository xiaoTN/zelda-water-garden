## 内容

## 可编辑性与边界

分镜、字幕、音轨共享同一时间线；工作台本次使用端口 5197，5198 已被另一服务占用。正式成片以工程 `npm run render` 导出为准：包含实测 AAC 垫头补偿，工作台通用导出按钮没有该补偿。工作台预览会在片尾多留约一秒编辑余量，交付 MP4 本身严格为 45 秒。

录屏原声可能含原游戏配乐，未另加音乐，因此没有把它标为“无 BGM 版”。未声称做过人耳试听或平台上传测试。手机 480 px 宽缩图中文字可读；有效标题约 70–71 px、辅助文字约 37–38 px，符合所选版式，但略低于审美指南按 1440 高度比例换算的建议，记为后续可调字号项。
