# 片刻 · 水光：宣传片关键帧 V01

2026-10-05，按用户要求先提供关键帧，等待画面反馈后再制作视频。唯美、宁静，以水面模拟器为主；45 秒时间线中，雪地与云海各占 2 秒。

用户指出小红书笔记文字会占用画面下方。因此此版先采用 1080×1440 的 3:4 构图，品牌与字幕放在上中部，主体动作集中于中间。顶部约 180 px、底部 360 px 留作低信息区域。此为本片的设计预留，不表示平台固定界面尺寸。安全区参考见 `safe-area.jpg`。

## 查看

- `storyboard.jpg`：按时间顺序排列的九张总览。

- `sources/`：在当前项目真实 WebGL 场景中采集的 1080×900 截图；不含生成或绘制的替代水面。

文字与配色沿用产品的宋体、青蓝水面、深绿底与米白 / 浅金文字。当前为静态构图预览；计划采用轻推近、局部跟随和柔和叠化，水滴、拨水、入水与雨声形成声音线索。结尾回到宁静，服从用户调性，不采用强节奏发布会式收尾。

## 采集与验证

`capture.html` 使用项目原有脚本与真实几何，通过 `capture-scene.js` 重现点按、滑动、落石、切换雨势和场景。仅采集页隐藏控件，并在目标状态冻结动画；业务源文件未修改。`capture-init.js` 固定随机种子；截图为一次采集的冻结结果，计时器与渲染调度仍取决于浏览器，不声称逐帧可复现的视频素材。

采集页需要在仓库根启动本地静态服务，例如 Python `-m http.server 39147 --bind 127.0.0.1`，访问 `/docs/promo-keyframes-2026-10-05/capture.html?shot=tap`；视口 1080×900。可用 shot：calm、tap、swipe、leaf、stone、rain、snow、cloud、end。

排版页 `?frame=1` 至 `?frame=9` 在 1080×1440 视口导出；`?frame=2&guides=1` 为留白示意。所有九张来源图片与排版图片已确认加载成功，并逐帧检查文本与主体下界；九宫格截图已人工检查，无游戏控件、提示条或文字裁切。主要画面下界为 1005–1019 px，标题下界不超过 451 px。下方 360 px 不放核心信息。

本次仅新增宣传片预览资料，没有改动 H5 源码或运行包。验证范围为图片尺寸、加载、顺序、文字与留白；尚未制作或验收运镜、转场和音轨。
