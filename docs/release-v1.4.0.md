# 水之庭 v1.4.0 · 指尖水花

2026-10-03。拨水和浮叶模式下，手指滑过的水面连续泛起细小水花。慢划轻柔，快划的水滴更多、飞得更高；沿途留下短暂的细碎亮色水痕和扩散涟漪。

原先按单次事件距离触发，细小触摸移动容易没有水花。现在累计移动距离，每 10 px 采样一次；低档每 16 px，单次事件最多处理 48 个采样点。水滴沿划动方向及两侧散开，起点、大小、速度和水痕形状加入轻微随机变化。出岸时更新指针位置，避免回到水面后连回旧坐标；每个采样点检查岸线和冰层。

水滴与原有点击、长按水花共享 150 / 60 个的上限；水痕最多 80 / 36 个，0.62 秒后移除，飞溅水滴最长 0.83 秒。减少动态效果时保留轻微水面反馈，不产生飞溅水滴。重置、尺寸变化和全部冰封清空水痕，页面隐藏与取消触摸沿用原有停止交互逻辑。不增加纹理、外部依赖或联网请求。
