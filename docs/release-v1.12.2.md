# 海拉鲁自然交互 v1.12.2 · 踩碎后的局部雪堆

修正踩碎雪球后碎雪摊得过宽、局部高度起伏不足的问题。碎雪仅堆在原雪球附近，堆积半径为球半径的 1.9 倍，形成三处较高的雪丘与较低的间隙；大球以更高的局部雪堆容纳体积，不再为了限制高度向远处扩散。边界处也只在附近现有网格内分配碎雪。

鞋底仍压出脚印，压出的雪在局部形成宽而平滑的肩部。鞋底材料转移限制边缘高度，避免窄尖峰；普通雪面上的原有脚印保持原来的范围与高度。重置恢复原有高度预算。

沿用同一三维高度场、雪面网格与世界空间光照。复用现有 RGBA 纹理的 G+B 通道编码更高的局部雪堆，保留精度并避免字节回绕；CPU 雪面高度、球体支撑和相机拾取使用相同高度。高雪堆启用更细的射线步长以准确拾取窄高的可见表面。没有新增纹理、网格或绘制调用。

验证远处高度完全不变、碎雪体积保持、不同大小及合并球的局部堆积、雪堆高低差、鞋底保留、边界堆积、纹理编码与高雪堆拾取。四种视口、两档画质、俯视 / 斜视、离线与上下文恢复继续回归。
