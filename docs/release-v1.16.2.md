# v1.16.2 — 固化用户选定的参数

根据用户提供的开发者面板截图，将以下数值写入项目默认配置与独立模块的回退默认值。截图内其余可见数值已经与默认配置一致，继续沿用；截图未显示的项目保持原有默认值。

| 参数 | 原默认值 | 选定默认值 |
| --- | ---: | ---: |
| 纸船大小 | 1 | 0.6 |
| 雪球减速摩擦 | 1.8 | 4.6 |
| 雪球甩动触发速度 | 1.2 | 3.8 |
| 雪球生长速度 | 0.075 | 0.035 |

新安装、离线包、正式容器和本机“恢复默认”均使用这些数值。本机仍允许实时调整，已有本机保存的个人调参值继续保留；需要重新采用项目默认值时，在开发者面板点“恢复默认”。

纸船模型、相机、碰撞、波纹推动以及雪球的世界坐标运动机制保持原有实现，只调整大小和运动参数。同步更新原有测试里的默认值期望与转向障碍的尺寸适配。

合并浏览器验证用较小雪球推向较大雪球，并按变形后的雪面重新投影手势终点，保证测试检查实际球体接触。

`npm run build` 通过：117 个单元测试、32 文件包检查、离线能力及兼容性审计、ZIP 结构与源码字节核对，零审计警告。纸船拖动/惯性/碰撞、纸船水流、雪球惯性/录音/默认值恢复的浏览器检查均通过，覆盖普通/低档与原生触摸回退。
