# 水之庭 v1.9.0 · 雨丝、雨势和雷电

原来的细雨只在水面产生随机雨点，空中没有可见的雨丝。现在雨丝分远、中、近三层落下，抵达落点后才推动水面、产生短促的小波纹。下雨按钮展开雨势面板，可直接选择停雨、小雨、中雨、大雨或暴雨；工具栏显示当前雨势。

| 雨势 | 默认雨丝数 | 雷电间隔 | 表现 |
| --- | ---: | --- | --- |
| 小雨 | 48 | 无 | 稀疏、细短雨丝，轻微风斜 |
| 中雨 | 95 | 18–30 秒 | 连绵雨丝，偶发远雷 |
| 大雨 | 165 | 8–14 秒 | 更长更快的雨丝，明显风斜、阴云与双段闪光 |
| 暴雨 | 260 | 2.8–5.6 秒 | 密集倾盆雨丝，频繁闪电、延后雷鸣 |

这些是互动视觉档位，不表示真实气象降雨量。开启中雨以上档位后，首次雷电等待时间为正常间隔的 45%，后续按表内区间随机变化。雷声延后约 0.3–1.6 秒，暴雨为 0.3–0.75 秒。默认静音，底部「声音」开启水声、雨声、冰裂声和雷声；雨声与雷声音量随雨势变化。

停雨取消尚未播放的雷声、闪电和雨丝；「平静」还清除阴云、水波与冰层。静音、切雨势和页面隐藏立即停止并释放天气音频节点；恢复页面保留雨势、恢复雨声，不补算后台雨点或补播雷声。浏览器回归发现暂停 AudioContext 后 onended 可能延后，已改为停止时同步断开和释放雷声节点。

天气使用已有的 Canvas 2D 覆盖层，复用 260 个粒子对象，不增加 WebGL 纹理、三角形或 draw call。低档粒子数约为默认的 45%，暴雨为 117 条；落水回调每秒最多 68 次，低档减半，只有水域产生波纹。完整冰面、露出水面的落石和岸石不产生液态雨纹。减少动态效果偏好会进一步减少雨丝、取消折线闪电并将闪光不透明度限制在 0.035。

所有音频由 Web Audio 离线合成，用户开启声音时创建并缓存雨声与雷声缓冲。页面代码为 Chrome 61 / ES2017 基线的经典脚本，ZIP 新增 weather.js，共 14 个静态文件。

验证证据位于 `docs/evidence-v1.9.0/`：四档手机雨势、暴雨闪电、Canvas 暴雨，以及浏览器回归报告。单元测试新增雨量递增、雨丝落点同步、停止时取消雷声、低档预算四项行为验证。

32 项单元测试通过。Edge 154 的 390×844、320×568、844×390、1440×960 四种视口验证了雨势选择、44 px 触摸目标、雨丝真实像素覆盖随雨量增加、暴雨重复闪电与延后雷声、静音及后台恢复。原有水面、浮叶、冰霜、落石、上下文恢复、Canvas 降级和离线 file URL 回归通过，浏览器错误数组为空。离线暴雨雷声不产生 HTTP 请求。
