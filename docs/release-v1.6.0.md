# 水之庭 v1.6.0 · 三维水面与流动贴图

2026-10-03。修正沿岸白纹过于固定的问题。此前是二维波动网格通过两个全屏三角形着色；现在水面为具有 XYZ 坐标、索引三角面和顶点位移的实际三维网格，使用倾斜 30° 的正交相机投影及深度缓冲。岸边植物、石头仍是原有二维背景，浮叶、水滴和冰碎片仍使用 Canvas 叠加。

## 渲染结构

- 三组不同方向的周期波驱动水面顶点高度，触摸波场同步进入顶点位移；冻结权重抑制起伏，岸边固定以避免水体离岸。地平面投影保持与触摸坐标一致。
- `src/water-normal.png`：256×256 无缝法线贴图，使用两层不同尺度、不同方向的 UV 滚动，叠加几何法线和触摸波场参与卡通明暗计算。
- `src/water-foam.png`：256×256 无缝泡沫贴图，R 存储细胞边缘、G 存储疏密噪声、B 存储细胞内部距离。白纹结合岸线距离、移动波前和纹理采样，产生靠岸、断裂、消散的过程。径向偏移有界，不随时间无限拉伸纹理。
- 两张图片均由 `npm run assets` 确定性生成，代码为 `scripts/generate-water-maps.cjs` 与 `src/water-maps.js`。不使用远程纹理、不依赖 Unity 运行时。
- 部分浏览器不允许将 file URL 图片直接上传为 WebGL 纹理；该情况下使用同一算法生成本地 Canvas 纹理，图案保持一致。缺失图片也走同一回退，无网络依赖。
- Canvas 降级模式保留二维水面，岸边白纹也改为推进和消散。

## 参考

[Unity Shader Graph 官方 Water 示例](https://docs.unity.cn/Packages/com.unity.shadergraph@17.4/manual/Shader-Graph-Sample-Production-Ready-Water.html) 描述了双层滚动法线、顶点波和接触泡沫的组合。此次采用对应的图形结构，用 WebGL 1 实现；没有直接复制 Unity Shader Graph 或声称为 Unity 引擎项目。

## 预算与验证

- 每帧 2 次 draw call；水面最高 128×128 格、16,641 个顶点、32,768 个三角形，低档最高 64×64 格、4,225 个顶点、8,192 个三角形。长宽不等的屏幕按比例减少短边细分。
- 6 张纹理，最大单边 1024；新增两张 RGBA8 贴图合计 512 KiB，无 mipmap。继续使用 DPR / 像素预算、慢帧降档、隐藏暂停、上下文丢失与恢复。
- 构建内 12 项测试包含新增网格索引边界、低档细分、投影 / 触摸对齐、触摸高度进入网格、冻结停止位移；包检查、目录审计、ZIP 与源文件逐字节核对通过。
- 浏览器验证增加实际网格规模、两张贴图加载、静置一秒岸边画面变化、file URL 纹理回退检查；四视口及原有完整交互回归报告、画面证据在 `docs/evidence-v1.6.0/`。
