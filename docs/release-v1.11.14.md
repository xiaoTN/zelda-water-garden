# 海拉鲁自然交互 v1.11.14 · 石头入水录音

落石在刚体模拟发出首次触水事件时，播放用户指定的入水录音。石头尚在空中、落到池底或再次碰撞时不重复播放。与轻点水滴和滑动水流使用独立的解码缓冲。

原始 MP3 完整保存在 `assets-source/audio/stone-impact.mp3`，来源与校验值见该目录的 README。运行时通过 `src/stone-impact-asset.js` 携带原始字节并由 Web Audio 解码，支持离线 file URL。保留录音原有起音及自然尾音，作为单次效果直接播放，不增加循环或额外淡入淡出。解码失败时沿用程序生成的落水声。

复用单次声音控制器，每份录音最多同时保留四个声源；静音、平静、场景切换或隐藏页面时停止并释放落石音频。长水流、雨声和雷声继续使用已有的淡入淡出。

上传包为 `artifacts/zelda-water-garden-minitool-v1.11.14.zip`，25 个离线文件。新增验证覆盖原始字节一致性、直接起音、声源数量与回收、真实 PCM 解码、实际触水播放时机、静音和重置，以及离线播放；完整验证记录见 `docs/evidence-v1.11.14/`。
