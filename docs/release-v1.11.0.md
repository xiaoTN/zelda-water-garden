## 设计与实现

沿用现有原生 WebGL 1 技术栈，增加独立的三维相机、投影、射线求交与四元数数学模块。所有资源随离线 ZIP 交付，不依赖 CDN。

- **雪地**：世界空间中的可变形三角网格。触摸通过透视相机射线与变形雪面求交，压实底面、雪槽、脚印和积雪边缘改变真实顶点高度；法线按实际高度求导。外围松树也由几何体构成。
- **雪球**：程序球体网格及轻微几何粗糙度。球心根据雪面高度和半径定位；滚动距离、方向与半径驱动四元数，纹理与球体共同旋转。球体参与深度遮挡，雪面上的软阴影由球心、半径和光线方向解析计算。选取球体使用射线与球体相交，拖动保留抓取偏移。每次最多 12 个球体。
- **云海**：带上表面、下表面与边界侧面的闭合网格。连续密度噪声产生起伏，拨云、聚云改变网格高度，风推动采样空间。几何以世界坐标经相机投影，支持俯视/斜视切换。它是程序几何云层，并非体积光线步进或流体求解器。
- **直接渲染**：雪地和云层使用页面 WebGL 画布，删除旧的 Canvas 2D 雪球、贴图云团、画布拷贝与降级绘制器；水面也不再以 Canvas 2D 重画整场游戏。
- **失效状态**：普通档→低档；持续慢帧则暂停并显示说明。无 WebGL/顶点纹理能力时显示明确状态。上下文丢失保留 CPU 场景，首次恢复重建低档资源，反复丢失不无限重试。不可见页面暂停。

参考仍为 shiloku 的 [Unity 动态云海](https://www.bilibili.com/video/BV1wj411x7hh) 与 [Unity 动态雪地](https://www.bilibili.com/video/BV1Eu4y1g7n4)。已下载的视频和抽帧留在本工具忽略的 tmp/reference-videos；本次再次查看云海接触表，关注三维沟槽、连续隆起及位移。视频、作者模型和纹理没有进入发布包。

## 预算与边界

| 项目 | 默认档 | 低档 |
| --- | ---: | ---: |
| 雪地 + 松树 + 12 个雪球 | 94,288 三角形 | 39,032 三角形 |
| 闭合云层网格 | 84,096 三角形 | 40,800 三角形 |
| 雪景 draw calls（含可选飘雪） | 最多 15 | 最多 14 |
| 画布像素 | ≤ 2,000,000 | ≤ 1,000,000 |

自然场景只有 256² RGBA 噪声和 320² RGBA 交互两张纹理，约 0.65 MiB，不使用屏幕截图作为场景贴图。默认雪球 1,408 三角形，低档 560。飘雪采用世界空间 GPU 点粒子，低档关闭。两个场景不同时提交 GPU 绘制。

雪球由用户拖动，尚未增加球与球的刚体碰撞；阴影是解析球体近似，松树与云层没有实时阴影贴图。雪槽和云沟是网格形变，效果仍有移动端网格密度限制；不宣称与 Unity 参考逐像素相同。
