# 水之庭 v1.7.1 · 石头障碍与实际水深

此前 v1.7.0 的 3D 深度缓冲只解决视觉遮挡，波场仍只识别池岸；水色用到岸距离代替水深，泡沫相位也只参考池岸。这导致石头没有真正阻挡波浪，其水下表面也没有形成浅水颜色。

现在将同一套岸地和石头三角形从上方栅格化为高度图，逐点取最高实体表面；新增一张最长边 512（低档 256）的 RGBA 纹理，RG 保存 16 位高度，B 保存到最近露出水面实体的近似距离，A 标记石面。

- 实际水深 = max(0, 当前三维水面高度 − 下方最高池底 / 石面高度)。水越浅，材质越偏浅青、越透明；深水更蓝。深度用于水色和透明度，时间噪声不再冒充深度。
- 波场从高度图生成障碍格。石头露出水面处不传递波量，采用无穿透反射边界；手指扰动的作用范围也检查障碍，避免直接在石头另一侧生成波浪。水下石面降低局部水深并减慢传播。
- 白纹以最近的池岸或石头边界为参照，局部波高和坡度负责变形。移除持续将泡沫相位推向水池外圈的时间项，以及以池中心为参照的径向摆动。
- 冰层不覆盖障碍格，冰封覆盖率只统计可积水区域。重置、尺寸切换、低档和上下文恢复重建 / 保留相应数据。

这是带水深和障碍的二维高度场波动近似，使用三维网格显示，不是完整的三维流体或 Navier–Stokes 求解；障碍、水深有有限网格分辨率。浅水传播系数带稳定性下限，不按现实单位标定。Canvas 兜底使用相同障碍波场，水色仍为简化渐变。

验证：新增真实三角面水深、阻挡 / 反射、扰动不可跨石注入、浅水减速和冰层障碍测试；图形验证读取实际材质中的水深，对比抹去石面高度后的结果。保留 3D 深度遮挡、泡沫联动与多视口回归。证据目录 `docs/evidence-v1.7.1/`。真机性能未实测。
