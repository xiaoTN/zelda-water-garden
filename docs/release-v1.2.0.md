# 水之庭 v1.2.0 · 冰霜

2026-10-03。保留用户认可的 v1.1 水面，新增原创的结冰与踩碎玩法。

## 交互

- 选择「冰霜」，轻点水面，晶纹从指尖向外展开，形成不规则薄冰；滑动生成连续冰径。
- 轻点冰面，先传播放射裂纹，约 140 ms 后打开水洞，伴随水花和抛起的碎冰；碎冰逐渐消散。其他模式也可以点碎已有冰面。
- 「一键冰封」由中心向外冻结整个池面，可逐块踩碎；「融冰」在约 1.2 秒内融化全部冰层。
- 冰层固定浮叶、阻挡水波，细雨不会在完整冰面产生水花。碎裂取消该区域尚未完成的结冰，水洞不会自动长回。
- 横竖屏切换和 WebGL 上下文恢复保留冻结区域与已碎水洞。「平静」立即清除冰层、粒子和待执行的碎裂。
- 手动开启水声后，冻结与碎裂使用高频合成音。减少动态效果偏好关闭飞溅碎冰。

## 实现与预算

冰层使用与水面同尺寸、固定容量的网格；与波面共用 RGBA 纹理，B 通道储存覆盖量。新增 256×256 晶面纹理，约 256 KiB。WebGL 仍为 1 draw call / 2 三角形，默认 DPR ≤ 1.5 / 200 万像素，低档 DPR ≤ 1 / 100 万像素。冰霜生长最多 24 组、裂纹最多 24 组、碎冰最多 90 片（低档新生成上限 40）；对象会按寿命移除。隐藏页面时暂停模拟与音频，Canvas 2D 降级保留结冰、碎冰、水洞与交互。
