# 水之庭 v1.9.7 · 更密的中雨、大雨与暴雨

根据反馈增加雨丝和落水雨点的密度，逐档拉开雨势差异：

| 雨势 | 空中雨滴（此前 → 现在） | 每秒有效落水上限（此前 → 现在） |
| --- | --- | --- |
| 小雨 | 48 → 48 | 20 → 20 |
| 中雨 | 112 → 168（+50%） | 65 → 100（约 +54%） |
| 大雨 | 240 → 420（+75%） | 160 → 280（+75%） |
| 暴雨 | 420 → 840（+100%） | 320 → 640（+100%） |

同步将短寿命雨纹池扩至正常档 384 / 低档 160，避免翻倍后的暴雨提前替换仍在消散的小涟漪。落水积分上限从 28 / 12 提高至 56 / 24，覆盖最大 80 毫秒模拟步长，防止较低帧率把暴雨密度卡回旧值。空中雨滴池按最高雨势预分配，动画中不扩容；低档仍按正常密度的 40% 工作，减少动态效果偏好进一步减少空中雨滴。单滴水纹半径、约半秒消散、触摸水波及音频保持上一版实现。

51 项单元测试、四视口 30 个浏览器场景、离线资源检查、构建、源目录审计、ZIP 字节一致性与 Python ZIP 内容审计通过，0 审计警告。更新既有回归阈值，确认暴雨在 60、30、12.5 次/秒的模拟更新下均能在八秒内落水超过 4,000 次；低档三十秒落水超过 6,000 次且不超过 7,682 次。浏览器检查各档实际空中雨滴数量、四档可见雨丝像素递增、连续拨水声、冰石遮挡、离线及降级路径；错误数组为空。
