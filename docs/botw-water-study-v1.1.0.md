## 原版与 v1.0 的差异判断

v1.0 的连续细线网格、近乎均匀的青绿色和弱反射，使水面更像装饰性材质。上面的截图显示，不同环境的原版水体差异很大，但普遍能看到更明确的反射、局部亮片、阴影与透明浅岸。这个判断来自视觉观察，不是对任天堂 shader 实现的断言。

## v1.1 实现

- 删除原先全池的两层正弦网格焦散。
- 一次生成 256×256 可重复纹理，存储多尺度波面法线与低频变化；动画中复用，不新增每帧 CPU 图像生成或 GPU 回读。
- 两层不同方向 / 尺度的移动法线，打散天空、树影和日光反射；较大的交互水波继续驱动折射与反光。
- 水底改成较中性的暖灰砂石，区分浅水透明度和深水青蓝色；调低过于细密的反射扰动与曝白面积。
- 触碰涟漪的亮边带不规则偏移与断续区间，弱化规整圆环。原来的波传播、衰减、多指输入、浮叶和雨滴保持联动。

水底与反射依然是原创程序化绘制。水面并未使用游戏截图贴图，也未声称使用游戏原版 shader。图片对照后的结果见 [新版预览](evidence-v1.1.0/iab-preview.jpg) 和 [手机版静水](evidence-v1.1.0/mobile-calm.png)。
