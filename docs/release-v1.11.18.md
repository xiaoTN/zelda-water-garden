# 海拉鲁自然交互 v1.11.18 · 场景声音淡入淡出

水面、雪地、云层切换时，旧场景的声音渐弱，新场景的声音渐强。三个固定音频通道共享原有总音量，约半秒完成主要过渡；快速切换时从当前音量继续衔接。

修复轻点、落石录音及雪地、云层交互音效在场景切换时直接停止的问题。录音保留最多约 0.65 秒的淡出尾音；雪地与云层短音效按自身剩余时长柔和收尾，结束后释放音频节点。正常短音效保留直接起音，长声音继续使用原有淡入、淡出与平滑音量变化。页面隐藏仍立即释放音频并暂停，恢复后继续当前场景。

验证包括三声道真实 WebAudio 波形的双向过渡与快速反转、录音普通起音和中断尾音、水面 / 雪地 / 云层 DOM 交互切换、落石尾音释放及快速返回无重播。离线上传包为 `artifacts/zelda-water-garden-minitool-v1.11.18.zip`，26 个文件；完整验证记录见 `docs/evidence-v1.11.18/`。
