# v1.12.0 滚雪球与碰撞合并验证

日期：2026-10-04。环境：Windows，Edge 154.0.4258.53。

- 「雪球」改为「滚雪球」。选择模式、轻点或按住雪面均不生成球；实际滑动后从零半径聚雪，松手保留，在空白处再次滑动创建新的球。重新点击模式不会删除已有雪球。
- `npm run build` 全部 90 项测试通过。覆盖零半径起步、按移动距离增长、有效旋转、最多 12 球、合并时半径立方守恒、连续合并、不同高度球体接触、快速移动的路径碰撞、合并球继续滚动不缩小，以及已消失雪球的指针失效。
- `npm run test:browser` 通过，共 66 个场景：慢帧恢复 3 个、水面 43 个、自然场景 8 个、形变 12 个。三份带错误数组的报告均为空。
- 四种视口（390 × 844、1440 × 960、320 × 568、844 × 390）验证按钮文案、点击与轻点不生成、两次滑动生成两球、真实球面拾取拖动、接触合并及合并后的球半径增大。`snow-multiple.png` 与 `snow-merged.png` 保存相应画面。双指按下不生成，分别移动后生成两球，取消触摸保留两球并清除指针。
- 复用真实 WebGL 球体和相同的三维支撑位置进行碰撞。两档满场 12 球均能被相机射线逐一拾取，深度测试开启。默认档 98,624 个三角形、740,610 渲染像素；低档 38,472 个三角形、329,160 渲染像素；各 14 次绘制，符合既有预算。
- 雪面接触、球体旋转、俯视 / 斜视、场景切换、重置、调整尺寸、隐藏 / 恢复、上下文恢复、离线运行及明确的 3D 不可用状态继续通过。水面音频与云层回归检查通过。
- 包检查、源目录审计、26 个 ZIP 文件的根入口 / 文件数量 / 支持格式 / 源码字节一致性及 ZIP 大小审计全部通过，无警告。见 `build.log`、`browser.log`、`audit.log` 及四份报告。
- 本地预览 `http://127.0.0.1:8773/` 已刷新并切到空白雪面的「滚雪球」模式；界面截图保存为 `rolling-mode-preview.png`。
