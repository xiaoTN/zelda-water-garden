# 海拉鲁自然交互 v1.11.16 · 默认播放声音

移除三个自然场景共用的声音开关、按钮图标样式及静音逻辑。声音默认开启；首次触摸、点击任意交互控件，或通过空格 / Enter 操作时，在用户手势中初始化并恢复 Web Audio。首次点水即播放水滴录音，首次开启下雨即播放雨声，无需额外开启声音。

保留滑动、荡漾、雨声和雷声的平滑包络；平静和场景切换继续淡出并释放水声，页面隐藏立即停止声音，恢复可见后继续当前场景。移除只服务于手动静音的延迟暂停定时器。浏览器不支持音频时保留说明并继续视觉交互。

界面初次加载不提前创建音频上下文，首次操作激活播放，以兼容浏览器的自动播放限制。兼容没有 PointerEvent 的鼠标与触摸事件路径。
