# 水之庭 v1.8.1 · 收敛落石弹跳

解决落石碰撞后被甩到远处的问题。保留刚体碰撞和同点连续投放，调整为低回弹、在落点附近短距离翻滚和堆积。

- 恢复系数从 0.16 降至 0.015，接触摩擦从 0.65 调至 0.75。
- 下落阶段增加随速度增大的阻力，避免高处生成和连续落石叠高产生过大的撞击能量；入水后阻力进一步增强。
- 加强水下横向阻力、接触时的滑动及滚动耗散，初始自转减小；没有锁死横向位置或旋转。
- 接触求解由 14 轮提高至 18 轮，接触刚度调至 200,000、松弛参数 5，减少密集碰撞时的瞬时推离。

确定性对比：手机比例 0.462 与横向比例 1.5，各 8 个固定随机种子，每组同点连续投 3 块石头，模拟 20 秒。记录每组所有石头相对投放位置的最大水平距离，16 组平均由 **0.5814 降至 0.2132 个场景单位，减少 63.3%**。入水后石头最低点重新升出水面的最大高度由 0.1632 降至 0.0118。后者同时包含被其他石头托起的情况，不等同于单次弹跳高度。该对比是模型回归数据，不是真机帧率测试。

新增回归约束验证散开距离及入水后抬升幅度，并继续检查碰撞唤醒、自由旋转、10 块连续投放、防穿透和固定时间步一致性。原旋转测试改为验证过程中实际发生旋转，不再要求落稳姿态必须偏转至少约 16°。

构建、包检查与 22 项单元测试通过；四种屏幕尺寸、重复落石、横竖屏、碰撞破冰、Canvas 兜底及离线 file URL 的浏览器回归通过。Python ZIP 内容审计通过，0 警告。静态包为 13 文件、433,604 字节。预览及回归证据位于 `docs/evidence-v1.8.1/`。
