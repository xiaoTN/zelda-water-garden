# 水之庭 v1.8.2 · 不规则石形与无弹性接触

投放石头由原先同高的底环和平底封面，改为三层错位、不同高度的环状采样点，加上偏心顶点和底点。17 个采样点形成不规则凸包，底部和顶部都由独立棱面组成；翻转后不再露出整块切平的底面。绘制与碰撞共享同一几何，最多 30 个三角形 / 块，合并缓冲预留 32 个三角形 / 块。岸石没有改变。

石头接触恢复系数从 0.015 降为 0，包括大石头相撞；质量仍随体积增长，保留挤动、侧滑、转动和自然落稳。接触刚度从 200,000 降至 100,000，松弛参数从 5 增至 8，降低穿透修正时的瞬时顶起。横向额外阻力略减：水下系数 6 → 5、接触系数 4 → 3，保留整体水阻和滚动耗散。

大石头正面互撞回归：两块最大规格石头，以各 0.7 场景单位/秒相向碰撞，移除重力和应用层水阻后单独验证接触求解；接触恢复系数为 0，最终反向速度约 0.037，远低于来速。零恢复系数不保证任意碰撞下位置完全不抬升：斜面接触、动量传递与堆积仍可能使石头转动或被托起。

16 组连续落石回归的平均最大散开距离为 0.1976 场景单位，最大 0.4030；该样本中入水后石头最低点没有重新升出水面。补充测试验证下部顶点分布、没有宽大的平面封底、完整几何缓冲和大石头接触耗能。

静态包仍为 13 文件，动态石头与阴影最多增加 420 个三角形、2 次 draw call。物理采用游戏效果近似，未做真机 WebView 性能实测。证据保存在 `docs/evidence-v1.8.2/`。
