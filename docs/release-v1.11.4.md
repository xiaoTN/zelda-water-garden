# v1.11.4 — 雪球接地阴影与人形脚印

## 修改

- 雪面上的雪球阴影按真实球心、半径和光源方向计算遮挡。保留环境光，仅遮挡直射光；阴影色来自雪面材质，与雪痕的阴面协调，不再把整个雪面颜色乘上一层灰黑色。
- 半影宽度随遮挡距离变化；球面与地面的距离控制接触处的小范围柔和暗部。所有计算基于雪面片元的世界坐标，没有额外阴影贴片或屏幕图层。
- 雪球放置从单点高度改为中心及三圈共 37 个支撑采样。球体曲面底部按雪痕与雪堆抬升，仅保留半径 2.5% 的微小嵌入，减轻悬空和穿入雪堆。
- 脚印采用左右镜像的鞋底形状：宽前掌、内收足弓、窄后跟。压实区域较平，外围仍接收挤出的雪量。扩大脚印和步距，使轮廓在移动端可辨认；步伐方向仍跟随拖动。

## 验证

- 新增足弓内外侧、前掌和后跟压深、排雪体积守恒测试。
- 浏览器新增滚动后球体在凹凸雪面上的接触与穿透量断言。
- 46 项单元测试、离线文件检查、源码审计、构建、ZIP 内容与产物审计通过。
- 完整浏览器套件涵盖慢帧、四种窗口尺寸、水面、雪地、云层、两种视角、上下文恢复、离线运行与场景边缘。
- 当前内置浏览器验证了脚印与雪球预览。截图和报告见 docs/evidence-v1.11.4。
