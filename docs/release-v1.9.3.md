# 水之庭 v1.9.3 · 雨滴与拨水共用水波

移除天气系统单独绘制的细小圆环和 384 个雨纹对象池。雨滴到达水面时直接调用点击、手动滑动复用的 splash 方法，由同一个 WaveField 生成和传播水波。雨波与手指扰动叠加，驱动同一水面网格、法线、白色波峰和浮叶，遵守冰层与石头遮挡。

保留俯视雨滴轨迹、四档雨势和雷电频率联动；有效落水预算仍为小雨 20、中雨 65、大雨 160、暴雨 320 次/秒，低档为 40%。删除原来每秒仅向波场注入 110 次（低档 44 次）的第二层限流，每个被接受的落点都实际扰动水面。每滴冲量随雨势和远近略有变化，范围 0.093–0.172，低于点击的 0.32；扰动半径使用同一个 splash 公式，避免密集雨滴变成整池同时抬高。停雨后波动由现有模拟自然衰减，平静会清空波场。

主分支已合入的宽阔落石波浪与最近 10 块落石自动替换保留。

浏览器回归直接观察运行页面中的 WaveField：核对暴雨有效落水数与成功波场注入数一致，确认真实波场有能量且未生成圆环；随后实际拖动鼠标，验证滑动和雨滴操作的是同一个波场，且数值保持有限。截图记录暴雨以及雨中拨水。原有四视口、冰石、音频、离线与降级回归继续执行。

验证完成：37 项单元测试、四视口浏览器回归、包检查、构建、目录审计、ZIP 字节核对和 Python ZIP 内容审计全部通过，浏览器错误为空，审计 0 警告。Edge 154 的暴雨采样记录 576 个有效落点、576 次成功波场注入；随后 18 次滑动输入与雨滴共用唯一波场，波场能量约 795.36，全部高度值有限。该采样用于核对真实注入与共享交互，不是设备帧率指标。
