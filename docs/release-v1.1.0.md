# 水之庭 v1.1.0

2026-10-03。根据用户“现版水面不像《旷野之息》”的反馈，检索并查看七张游戏实机图，重做水材质。详见 [图片对照与修改依据](botw-water-study-v1.1.0.md)。

本次变化：移除满池网状亮纹；加入细波打散的日光反射、天空和树影倒影；增加浅岸透明砂石与深水色差；将触碰亮圈改为不规则断续波峰。晨光 / 暮色 / 月夜保持各自的高光颜色。
