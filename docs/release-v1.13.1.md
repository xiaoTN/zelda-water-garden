# v1.13.1 — 退出后重新进入的声音恢复

修复缓存页面返回时音频恢复遗漏。返回事件可能是 `pageshow` 或 `focus`，旧实现只在 `visibilitychange` 中恢复音频；已有上下文则仅处理 `suspended`，遗漏移动端系统中断和已关闭状态。

现在页面退出时统一停止声源、暂停音频及帧循环，重新进入时恢复当前场景音乐与选中的雨势。异步暂停完成后会再次检查页面是否已经返回，避免晚到的暂停造成静音；异步恢复完成时也会检查是否已退出。`interrupted` 与 `suspended` 均会尝试恢复，系统拒绝时保留下一次用户手势的重试机会；已关闭上下文在再次激活时释放旧音频图并重建。保持原有长音淡入淡出、短音原始起落与默认声音开启。

## 复现及验证

新增 `node scripts/audio-reentry-check.cjs`，已加入 `npm run test:browser`。测试使用真实 WebAudio、音乐声源和主输出上的 Analyser，要求正在运行、只有一个当前音乐声源且有非零 PCM；不是只检查逻辑上的播放标志。

修复前确定性复现：缓存页面 `pagehide → pageshow` 后出现 `state: suspended`、无法恢复可听输出，测试失败。修复后覆盖：

- 缓存页面重新进入，无需 `visibilitychange`；
- 系统 `interrupted` 状态及自动恢复被拒绝后的手势重试；
- 四次快速退出/返回，注入 60 ms 延迟的旧暂停，等待其完成后确认仍然可听；
- 水、雪、云三场景重新进入；
- 选中小雨的环境声恢复，以及上下文被关闭后的重建和短音播放。

普通重入保持 1 个上下文；系统关闭后重建为第 2 个上下文。检查无页面错误。详见 `evidence-v1.13.1/audio-reentry-report.json`。

`npm run build` 通过：100 个单元测试、30 个离线文件的包检查、源码审计及 ZIP 核对，零审计警告。音乐、音频重入、渲染恢复、水面和自然场景浏览器回归分别运行，报告位于 `evidence-v1.13.1/`，完整自动化截图保留在本地 `tmp/browser-evidence-v1.13.1/`。浏览器为 Edge 154；移动端系统中断采用可控注入，尚未在小红书真机容器实测。
