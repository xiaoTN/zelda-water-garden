# v1.12.1 脚印踩碎雪球验证

日期：2026-10-05。环境：Windows，Edge 154.0.4258.53。

- 选择「脚印」只切换模式；轻点真实球面或按住拖动经过球面会踩碎命中的雪球，其他球保留。踩碎后不再拖动球，碎雪堆回雪面，球心留下鞋底凹痕。
- `npm run build` 全部 93 项测试通过。新增验证雪球体积按三维半径换算回高度场、脚印与周围隆起同时存在、已踩碎指针不能再次滚动或重复摊雪、靠近边界或原有高雪堆的体积保持与高度范围、非目标雪球保留及重置。球体体积回填误差低于 0.0001 立方世界单位。
- `npm run test:browser` 通过，共 70 个场景：慢帧恢复 3 个、水面 43 个、自然场景 12 个、形变 12 个。三份带错误数组的报告均为空。
- 四种视口（390 × 844、1440 × 960、320 × 568、844 × 390）、两档质量、俯视 / 斜视共 16 组踩碎交互通过。触摸轻点与鼠标拖动都使用相机射线命中的球体；目标消失、另一球保留、旧球无法滚动、鞋底凹痕及附近实际世界空间高度上升均通过。390 × 844 视口附近雪面升高约 0.11 世界单位；1440 × 960 约 0.18 世界单位。详见 `nature-browser-report.json`。
- `snow-crushed-footprint.png` 保存自动化踩碎与周围堆雪画面。`crushed-preview.png` 保存实际用户预览中从滑动滚球到轻点踩碎、留下脚印的画面。预览 `http://127.0.0.1:8773/` 已刷新；另留一个雪球并切到脚印模式供直接试玩，见 `stomp-ready-preview.png`。
- 离线文件加载的触摸回退验证踩碎、堆雪与脚印通过；场景切换、调整尺寸、重置、页面隐藏 / 恢复、WebGL 上下文恢复与明确的 3D 不可用状态继续通过。原有多雪球滚动、碰撞合并、雪面支撑、水声与云层回归通过。
- 沿用既有三维雪面高度网格和滤波、材质、光照、深度与拾取，未增加 GPU 资源。满场 12 球默认档 98,624 个三角形、低档 38,472 个，均为 14 次绘制；逐球拾取与深度测试继续通过。
