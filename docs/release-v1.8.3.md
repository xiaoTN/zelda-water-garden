# 水之庭 v1.8.3 · 石堆接触稳定性

修正同一点连续落石后，互相挤压的石头持续微振或休眠后反复被唤醒的问题。保留不规则凸包、零恢复系数、质量差异和自然侧滑；固定物理步长仍为 1/120 秒。

## 诊断与修正

用实际池底和岸石几何、固定随机种子重放重复落点。最小场景为两块石头：20 秒后仍有两块活动，最后 5 秒出现 4 次重新唤醒，最大残余运动指标（线速度 + 半径 × 角速度）0.08839。

1. 池底高度场和额外水平地面重叠，形成竞争的接触修正。分别禁用任一支撑面，最小复现都消失。现仅保留覆盖整个池塘的高度场及外侧边界，不再添加重叠地面。
2. 多棱面碰撞产生冗余摩擦约束。三块石头种子 10 的残余运动为 0.23183；单纯把求解迭代数翻倍仍有 0.18885。启用 Cannon 的接触面摩擦合并后，残余运动归零。
3. 单体休眠会让相接触的石堆处于一半休眠、一半活动状态。改为按动态接触图判断整组静止：整组有支撑、线性与角运动持续低于阈值 0.7 秒后共同休眠；保存休眠支撑关系，新碰撞时整组唤醒。
4. 慢速新接触也必须唤醒休眠邻居。种子 14 的三石场景，旧碰撞速度阈值使一块石头把睡眠邻居当作无限质量物体，持续微振达 60 秒；取消该唤醒门槛后正常落稳。仅活动动态物体的新接触触发唤醒，不由静态池底触发。

休眠阈值使用线速度平方 + 半径平方 × 角速度平方，避免小石头轻微转动被当作强烈运动。新碰撞仍能推动已落稳的石堆，未用强制固定位置掩盖持续受力。
