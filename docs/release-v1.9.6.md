# 水之庭 v1.9.6 · 小雨纹与连续拨水声

雨滴原来通过 `splash()` 使用触摸波浪的扰动半径和传播求解器。即使降低单滴强度，雨波仍以手指水波的传播速度扩散，并受同一阻尼控制，形成半径过大、持续过久的水纹。滑动则每隔约 120 毫秒重复播放短促噪声和降频正弦音，听感接近连续滴水。

雨滴现在在同一 `WaveField` 中维护局部短寿命高度，与手指波浪相加后上传已有水面纹理、更新网格和采样。每滴寿命为 0.402–0.49 秒，波峰半径从高度的 0.003 倍按每秒 0.042 倍扩展，最大约 0.024 倍；平方衰减让外扩的波峰快速变淡。390 × 844 视口中最大波峰半径约 20 像素，实际可见范围更小。触摸、滑动、长按及落石继续使用原有较宽、持续更久的波浪响应。

雨纹使用固定池（正常档 192 / 低档 80），仅计算每滴附近的小块网格。新增一张 CPU 高度数组，390 × 844 视口约 68 KiB，不增加 WebGL 纹理、网格或绘制次数。雨波不进入触摸传播求解器，不模拟远距离传播或岸石反射；干燥网格和冰面不接收雨滴高度。Canvas 降级绘制相同寿命和半径的小圈，并按湿润网格、冰层截断。停雨后已有雨纹在半秒内消散，「平静」立即清除。

连续拨水声使用预生成的水流噪声和随机短气泡噪声，不再在滑动途中重复触发滴水正弦音。两路循环音频通过高通、低通与带通滤波形成柔和拨水和细碎气泡声；移动速度控制音量及滤波频率，参数平滑变化。停手约 90 毫秒后渐弱，最后一次移动后约 400 毫秒释放节点；松手立即开始渐弱，静音、重置、页面隐藏和尺寸变化释放节点。长滑动复用两个缓冲和同一组音频节点。点击、落石、冰裂及天气音效保留各自原有响应。拨水声仍为程序合成，未通过真人听感或手机扬声器验收。

验证完成：51 项单元测试、四视口浏览器回归、离线资源检查、构建、源目录和 ZIP 审计通过。新增测试确认雨纹不会到达手指宽波范围，半秒后没有残留高度，雨与触摸高度同时打包，冰石遮挡和重置有效，暴雨工作量有上限；100 次音频更新没有增加缓冲或节点。浏览器验证真实滑动时声音持续、静止时淡出、恢复移动时再次响应、松手后回收、静音即时释放，同时保留原有降雨、冰、鱼、落石、上下文恢复、Canvas 降级及离线 file URL 场景。具体报告和截图见 `docs/evidence-v1.9.6/`。
